# 回归与发布验收

这是可重复执行的检查清单，不是某次提交已经通过的证明。0.1.0 问题修复的要求作为后续设计与回归基线。每次交付记录提交、数据来源、命令结果、跳过原因与实际截图；真实存档、日志和截图放在忽略的工作目录。

## 数据与状态

- [ ] 单人、多人存档都可解析；城市与模拟时钟正确；输入原件不修改。
- [ ] 公司稳定身份、同名消歧、同公司多人归属、空选择均正确。
- [ ] `[start, end)`边界、上一完整周／日、自定义取消／非法范围、月末和历史不足正确。
- [ ] 0、缺失、负值、部分小时、缺分母与不完整周期分别保留；不补零、不造未来观测。
- [ ] 现金流、存量、加权比值、最后日摘要、同刻总体遵守[指标口径](../reference/history-metrics.md)。
- [ ] 线路缓存与重算、时刻表发班、核定速度、创建／改线及周化财务遵守[线路指标](../reference/line-metrics.md)。
- [ ] 打开、拖放、取消、错误、换文件、清空、快速重复查询不会泄漏旧快照或可用导出状态。

## 图表与界面

- [ ] 原生和图表提示底色清晰、不被来源控件样式污染；已完整显示的信息不机械重复，确实省略或需要消歧的内容可读取。公司称谓一致，城市与统计图没有同值的重复标签口径。
- [ ] 每个提示入口的内容、顺序、精度、单位、日期与缺失状态有逐项确认记录；只实施已确认范围，小图隐藏常驻数字后仍能访问实际数值，键盘辅助信息保留。
- [ ] 启动 helper 是应用窗口大小的实色表面，至少验收 960×680；与主窗口首帧背景及标志位置连续，不扩展成显示器全屏。
- [ ] 欢迎层覆盖导航和顶栏区域；实际截图包含标志居中、平滑上移中间帧及最终打开入口。约 333ms 过渡不中断输入、不额外等待；关闭系统动画时直接显示终态。
- [ ] 欢迎按钮与 `.save` 拖放可启动首次解析；对话框取消仍保留欢迎层。解析／图表准备时进度层覆盖窗口，取消／失败可重试，成功准备后切页，快速切页／隐藏不遗留动画或效果。
- [ ] 欢迎提示及完整显示文字没有重复 tooltip；截断错误仍可读取完整内容。窗口 resize、125%／150% DPI 和键盘打开入口保持可用。
- [ ] 默认、多公司、同期互斥；选两家公司不自动改变模式；同期每家公司只有自己的两个周期。
- [ ] 单公司存档禁用公司／网络的多公司对比，程序化激活和恢复设置受同一门禁约束；更换单公司存档恢复默认／总体，多公司存档单选／空选不自动换模式，同期仍可用。
- [ ] 禁止出现“卡片基准”、最大车辆卡片口径备注及擅自新增的说明／内部信息；车辆标题固定为“车辆”，平均／最大切换及 resize 均不改名。新增说明或名称变化有用户逐项确认，不能由开发者自行补充。
- [ ] 最大车辆值按所选公司当前线路需求合计，真实零与缺失区分；无历史涨跌或虚构峰值，XLSX 与快照一致；平均车辆历史图不随摘要开关变化。口径留在指标文档，不占用界面。
- [ ] 公司与同期统一 `SeriesLegend` 色柱，名称、色阶、透明度与绘图一致；无“左／右、上／下”替代图例。
- [ ] 普通、放大、PNG 的柱间距、两端圆角、字体、字号和配色一致；负值与零基线正确。
- [ ] 放大堆积分段标签和整柱合计均实际绘出，小段、0、负值、长数字不丢；上方摘要卡保留，下方表格与操作说明不恢复。
- [ ] 公司、网络、城市、最新信息放大图在当前窗口内展开，主窗口大小、顶层窗口数不变；普通尺寸及最大化时绘图区、摘要和外框均有不透明白色衬底。“缩小”图标文字按钮清晰可达，鼠标／触控／键盘及 Escape 同窗收回，保留分类显隐（含全部隐藏）、原查询、类型、身份、来源焦点及页面滚动。
- [ ] 放大与缩小过渡有实际中间帧且可中断，系统关闭动画时直接到最终状态；窗口 resize 同步详情，来源隐藏／销毁／快照替换清理详情及动画，不将旧选择回传到新状态。窗口系统关闭仍关闭应用。
- [ ] 960×680 下两家公司六分类同期客流详情在开启／关闭动画时均完整显示图底与横轴；不能保留初始窄宽度测出的过高下限。起始及收回中间帧摘要与画布不重叠，终态及窗口 resize 后按当前宽度重新排布。
- [ ] 各页小图实际绘制及紧凑 PNG 无常驻数字数据标签，覆盖单系列／分组／堆积柱、折线、横条与环图中心／图例，坐标与身份仍可读；放大标签保留。
- [ ] 永久或过渡透明效果存在时，静态 PNG 仍含完整图形及正常配色；导出恢复原效果状态，不等待或改变动效设置。
- [ ] 显式启用动画时，图卡首次出现、首页分类卡、子页切换、放大图与摘要折叠／展开有真实中间帧及完整终态；400×190 图卡与 960×680 页面无黑闪、消失或摘要行重叠。动画不替换画布、不更改快照、不额外查询，导出与静态结果一致。
- [ ] 系统关闭动画或减少动态效果时立即显示终态；先无动画折叠再启用动画展开从零高度开始。快速反转、切页、隐藏与销毁正确清理临时效果、布局冻结和高度限制；不得为验收强改系统动画设置。
- [ ] 切换子选项卡与悬停线路亮点不增加描边，鼠标焦点不冒充键盘焦点；静止卡边框与键盘焦点仍可见。
- [ ] 分类全部隐藏仍是空选择；类型切换、放大副本和导出不改变分母、数值或能力集。
- [ ] 400×190 紧凑图卡仍有绘图区和日期标签；960×680 主窗口及宽屏无标题／文件／操作遮挡，无整页横向滚动。
- [ ] 长名称、重名、长数值、加载、空数据、错误、悬停、键盘焦点、125%／150% DPI 均可用。
- [ ] 反复更新导出菜单至少 40 次，行数与高度只取决于当前动作；首尾／连续分隔不生成空白，禁用状态、动作触发与键盘选择保留。
- [ ] 960×680 及 DPI 缩放窄窗：首页公司／制式控件无截断冲撞，统计长公司名与选中标签不撑宽页面或裁掉移除图标；提示内容按逐项确认的口径验收。
- [ ] 最新信息中型数值实际绘制为共享 600 字重，最大核心数值为 700，标签和单位保持 400；长值仍完整且不与单位重叠。
- [ ] 六项 KPI 与固定四图完整，不出现额外指标选择器；摘要折叠释放真实图高，resize 不反复重建图或发起查询。
- [ ] 最新信息亮点、Top10、班次构成、钻取返回、三类提醒及已读状态来自有效真实范围；导出状态与快照一致。
- [ ] 线路时刻表覆盖全部启用、全部未启用、混合与启用零班次：不显示“未启用”选择项或记录，零班次仍显示 0 班，午夜有效时刻保留，高位运行日标志与缺失运行日不误判为停用。无可展示内容时显示“暂无已启用时刻表”，不留下星期、摘要、图例或展开入口。
- [ ] 启用→未启用→启用线路切换及清空后，班次、失效星期选择、摘要提示、悬停和滚动位置无残留；普通与展开视图一致，原始班次／统计字段与 XLSX 导出不因展示过滤改变。
- [ ] 使用真实 Qt 触屏设备事件验证欢迎／首页／线路／统计控件点按只激活一次；从图表、文字、卡片和按钮滑动可滚动内容，表格位移不误当行数；原有鼠标、键盘和精密滚轮仍可用。
- [ ] 图表触控检查与鼠标共享真实取值；已缩放放大图横向平移不误触选择。长按只触发已有右键上下文动作，文本编辑／选择、滑块和菜单手势可用。
- [ ] 触控取消、多指、页面隐藏／失焦及目标销毁后无延迟点击、长按菜单、按下或拖动残留；Qt 事件与截图验收不等同于物理触屏验收，无硬件时明确记录限制。
