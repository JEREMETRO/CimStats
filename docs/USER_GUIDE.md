# CimStats 用户指南

## 打开存档

用"打开存档"按钮或直接将 `.save` 文件拖入主窗口。等待解析完成后即可浏览统计数据。切换文件会建立新任务，旧结果不会回填。

## 时间范围

日期来自游戏模拟时间。默认显示上一完整周，可切换为上一完整日或自定义范围。没有基准数据时不会显示变化指标。

## 页面说明

### 最新信息

城市与模拟时间摘要、运营概况、线路亮点、趋势图和关键变化提醒。"今日"按模拟时间计算。

### 线路查询

按条件筛选线路，查看详细信息和只读时刻表。计划班次与已完成客流分开显示。

时刻表隐藏明确“未启用”的记录和分组，保留已启用时刻表的零班次日组及午夜班次。没有可展示内容时显示“暂无已启用时刻表”；运行日未知的班次仍可查看诊断。切换线路会清理上一条线路的内容，展示过滤不改变统计或导出。

### 统计数据

**公司数据**：现金流、公司价值、月票、满意度、声誉、受欢迎程度。默认分别展示各公司；多公司模式可横向对比；同期模式比较本期与基准区间。

**网络数据**：设施、车辆和客流按已选公司计算。总体“出行量”使用全市公共交通行程，包含所有公共交通制式，跨公司换乘只算一次行程，不包含步行或私家车；总体换乘系数也使用全市范围。这两项不作同期或基准比较，勾选公司不改变数值。公司视图及票制／覆盖区数明细显示公司参与行程次数，各家公司数值不能直接相加作为去重出行量。摘要保留车库/站点、平均/最大车辆、客流/出行量。总体覆盖率暂不显示。

**城市数据**：全市统计，不受公司选择影响。五项摘要与六张图；交通方式有效构成才画饼图。

## 图表操作

- **图例显隐**：点击图例项切换曲线显示，不改变数据计算。
- **悬停详情**：查看实际日期、系列名称、数值和单位。
- **同期图例**：色柱图例区分本期与实际对比周期，公司对比使用同样的色柱标识。同期各公司单独显示，不混入其他公司。
- **图形切换**：部分图表支持总量/条形图/折线图/饼图切换。
- **放大**：使用图卡的放大按钮查看细节；双击图内恢复缩放。
- **折叠/恢复**：摘要区域可折叠以显示更多图表。

## 数据导出

导出前确认查询范围、时间粒度和保存位置。PNG 图表和 XLSX 工作簿使用同一查询快照，确保数据一致。

## 常见问题

**有值却无变化？** 可能没有有效基准区间。真实持平与缺失基准会分别显示。

**只有一个数据点？** 一日范围配日粒度只有一个数据点，可切换小时粒度查看日内变化。

**"—"是什么意思？** 表示数据缺失或不可计算。0 表示真实零值。

**加载失败？** 请确认使用 Cities in Motion 2 的 `.save` 文件。如问题持续，请提交 issue 并附上版本、游戏版本和错误信息（移除个人路径和存档名）。

## 数据说明

解析结果写入独立任务目录（开发模式为根目录 `jobs/`，独立程序为 `%LOCALAPPDATA%/CIM2_SaveStats/jobs/`）。存档本身只读，不会被修改。详细指标定义见[指标口径](DATA_DEFINITIONS.md)。

## 地图显示

打开存档后选择左侧“地图显示”，页头可切换单线、线网和规划，选项卡排版与统计数据一致，各自保留筛选、视角和面板布局。右侧标签控制图层、线路与显示方式；道路和建筑遵循存档真实几何。线网客流筛选、排序和染色共用来源：存档模拟时间在 23:00 起使用今日客流，此前使用平均客流，缺失显示“—”。

拖动面板标签可将其移入地图区域，拖回右侧重新停靠；浮动面板支持固定、折叠与调整尺寸，“恢复默认布局”恢复当前预设的默认布局。左上搜索线路后进入单线展示，也可从线路查询详情点击“地图上展示”。右下角可缩放与复位，导出菜单中的“地图图片 PNG”保存当前地图视口。

线路查询和地图各线路搜索入口共用规则：搜索线路名称、线路号、可见的制式或公司名称，不搜索内部对象编号、日期、客流和财务数值。纯数字仅匹配线路名称与线路号，支持数字子串；英文线路代码不区分大小写，全角数字也可搜索。

线网的公司、制式、盈亏、客流、运营时间和线路选择可分别展开。修改后点击该块“确定”，条件才生效并自动折叠；其他块的未确认编辑会保留。标题靠左、折叠箭头靠右，摘要显示已确认的条件和实际结果，例如“周三17:00-18:00 已选：22条”，优先一行显示，放不下才换行；没有条件时留空。重置恢复默认筛选，显示和图层设置即时生效。

客流可手输下限、上限或拖动双端滑块，下限从 0 开始，滑块采用幂函数，让 5000–15000 的中间范围更容易拖动；最大有限值为 50000，最右侧为独立 ∞ 档。默认显示 0 至 ∞；明确确认范围后，缺失客流不计作 0。客流口径只显示日期或“平均客流”，与“确定”同一行、口径靠左。运营时间的开始、结束输入各有独立标题，星期、时间滑块与手输时分同步；时刻模式只编辑开始时间，时段可跨午夜，停运间隔仍保留。

“盈亏”按周化收支分类：净利润绝对值不超过支出的 2% 算作持平，其余按正负区分盈利、亏损，原利润金额不变；缺失另列。平均间隔染色可选择日间（默认）、高峰或全日，高峰使用存档所在周周一至周五的有效班次。切换进入客流或平均间隔染色时站点默认隐藏，可随后手动打开，站名偏好保留。

地图图片需等待当前视角的清晰画面就绪后才能导出。线网面板与底栏的“已选”数量均为所有筛选后的结果，临时被筛选排除的线路仍保留原来的勾选。

单线右侧提供“线路列表”和“线路信息”两个一级入口。列表可按制式、名称、开线时间、客流或班次排序，并切换升降序。没有当前线路时默认显示完整列表，可直接点选、用上下键浏览或搜索；选中后可查看信息，随时返回列表继续浏览。地图左上和信息面板搜索也可选择完整目录中的线路；已有线路显示时，左上搜索框收为搜索按钮，鼠标悬停展开，输入时保持展开。单线默认选择上行，可切换下行或双向，信息只分“线路信息”“客流数据”两类。线路长度、核定时间和速度集中放在站点数之前，车库及开线、改线日期位于这一组之前。当前方向长度按原生道路里程累计，核定时间取该方向起站至末站的保存到达偏移之差，速度用对应运营区段长度和时间计算；只在双向或完整环行、单行时显示原全线里程与核定时间。空放选择调整长度，客流和班次保留整线口径。线网运营时间筛选以时刻表首末发班为准，末班之后不再选中。

规划用于搜索、选择已有线路进行比选，不需要保存方案。建筑强调默认开启，选中线路后仍保持；可结合社会群体与住宅、工作、休闲功能查看建筑。点击建筑可打开游戏原生规则查询的全公司服务线路菜单，搜索、逐项选择或全选可绘制线路；不可用与确实无服务分别显示。

方向、染色和叠放排序互相独立；三个方向模式都保留单行线路。更多口径见[地图显示](requirements/map-display.md)。

显示设置可分别调整各制式的线路粗细，选择“区分上下行线形”后，整条往返线路以下行实线、上行虚线显示。仅显示一个方向时使用实线。只属于隐藏方向的站点同步隐藏，共享站保留。

建筑可按社会群体筛选，颜色表示其住宅、工作、商业／休闲等功能，深浅沿用游戏数据菜单的相对容量口径。线网的“强调建筑密度”在无可见线路时默认开启，有线路时默认关闭；手动选择会保留，点击“自动”可恢复自动切换。规划预设默认保持强调。

水上巴士缺乏可用的运营路径，因此不在地图线路入口中显示；线路查询与统计仍保留。站点随关联线路显隐：全部关联线路隐藏后，站点及站名自动隐藏，重新显示任一关联线路后恢复。
