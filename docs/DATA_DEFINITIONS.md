# CimStats 指标口径索引

各项指标采用以下口径，源码入口列于文末。详细契约见[历史缓冲区与指标](reference/history-metrics.md)、[线路指标](reference/line-metrics.md)和[字段清单](reference/field-inventory.md)。

## 范围

日期基于模拟时间，起点包含、终点不包含。有限历史外缺失，不补零、不造趋势。公司用稳定身份关联。网络设施、车辆和客流按既有已选公司范围计算；总体模式的公共交通出行量及其换乘系数使用全市范围，与勾选公司数量无关。城市指标直接用全市历史。

城市同期沿用全市范围，按各自实际窗口分别聚合本期和对比期，再按相对时间排列。仅对比期存在的类别仍保留，本期对应位置为缺失；零观测保留为零。交通方式饼图分别核验两个周期的完整类别与共同分母，不将缺失或无效对比期当作零占比。核心指标默认使用自动基准，同期使用用户所选窗口；工作簿记录分析模式、两个窗口、每行所属周期及两个周期的原始观测。

## 聚合规则

|指标|规则|
|---|---|
|现金流|期间增量合计，区别于期末余额；按核实比例换算|
|公司价值|期末分项合计，不跨小时相加、不重复除100|
|满意度/月票/声誉/受欢迎程度|各自分子分母或时点定义，不统一简单平均，满意度允许负值|
|线路/站点/车库|最新有效存量；总体对齐同一观测时点，不拼不同日期|
|网络平均车辆/覆盖率/换乘系数摘要|窗口最后一天日内统计，不改成整段平均；趋势按桶展示|
|总体平均车辆|时间对齐合成，保留权重与缺测；历史图始终使用平均运行车辆|
|最大车辆需求数|当前所选公司线路的“理论最大车辆需求数”（原始“最大配车数”）逐线合计；属于存档当前需求，不是历史运行峰值|
|客流|登乘次数的期间计数，分制式与分群体客流不重复相加|
|公共交通出行量（公司分类）|原生公司 `trip-types` 计数，保留票制／覆盖区数分类；同一次跨公司行程可分别计入各家公司，不能将公司数值之和解释为去重出行量|
|总体公共交通出行量|原生全市 `public-transport` 的计数分子，而非其百分比或分母；覆盖所有公共交通制式，排除步行和私家车，跨公司换乘只计一次行程|
|换乘系数|总体使用全市登乘次数／全市公共交通行程次数；要求全部已序列化公司、分类与城市计数在相同有效小时配对。公司模式使用本公司登乘次数／参与行程次数；最后日摘要按日内规则|
|人口|最后有效观测，不累加|
|城市出行量|全市 `trip-number` 包含公共交通、步行和私家车；窗口累计、柱为桶累计，不冒称每日均值|
|平均出行时间|真实有效分母加权，不用人口权重替代，缺分母不可计算|
|交通方式|同一总体有效构成才画饼，不强制归一化|
|道路/轨道密度|分别取最细有效观测峰值，不取周期均值峰值|
|经济增长/利率|沿用核实字段，不擅称GDP或年化|
|能源价格|货币，不编造人民币/升单位|

站点历史总数不宣称空间去重。多公司总体覆盖率暂不显示；小时平均运行车辆不能推导瞬时峰值。最大需求采用当前线路字段，任一所选线路字段缺失或无效时合计不可用；没有线路的有效公司需求为 0，未选择公司仍为缺失。当前需求不与历史周期作涨跌比较，导出保留相同范围、数值和当前值说明。零与缺失分别呈现，具体完整性按源码及可复算测试验证。

最后日摘要的当前实现位于 `network_model._last_day_result`：从窗口结束时刻向前确定最后一个自然日，仅取与所选窗口相交的观测。车辆先按有效小时对齐分类，再计算有效小时均值；覆盖率汇总日内分子、分母后计算比例；换乘系数使用该日配对客流合计除以出行量合计，**不是简单平均各小时系数**。最后日不足全天或观测缺失时保留不完整标记，不偷偷退回更早的完整日。

## 比较和显示

有基准才显示涨跌/持平；百分点与相对百分比区分。颜色、领先/落后不代表所有指标的经营好坏。图例/曲线显隐不改变分母，导出使用同一查询快照。

界面数值、图表实际值、比较提示、复制摘要和导出数据最多保留两位小数，平均运行车辆数最多一位；统一向零截断，不四舍五入，省略不必要的末尾零，截断后的负零显示为 0。原始观测和统计计算保持原精度，只在呈现及导出边界处理。百分比按显示的百分数截断，Excel 百分比单元格仍存储对应的比例。线路／公司缓存工作簿在另存导出时处理副本，保留源文件、公司标识、日期和字符串。

总体的全市公共交通出行量及其换乘系数不作基准期／同期比较；其他指标及公司参与行程的既有比较不受影响。公司分类明细显示“公共交通出行量”，沿用原生公司计数；同一次跨公司行程可能计入多家公司。缺少原生城市计数时显示缺失，不退回公司计数和。历史槽没有旅程身份，不能通过居民、日期或当前公司名录反推任意公司子集的去重行程。

## 地图数据与查询

单线导出沿用真实线路对象身份、公司显示名、方向指标与长度倍率。方向选择不拆分全线客流、发班和财务；站标显隐不改变站数与里程。成品毫米与像素换算为 round(mm / 25.4 × ppi)，不使用屏幕 DPI 代替输出精度。

`MapRoute.depot_leg_paths` 保留序列化原腿的出库／入库边界，原有扁平 `depot_paths` 不改写。`depot_id`、`depot_name`、`depot_position` 只从线路首记录稳定对象身份对应的真实 `DepotData` 建筑读取，缺失保持空，不以路径端点推断车库位置。旧快照缺少方向腿关联时，不按连续段猜测空放上下行归属。

公司品牌保存原始 `m_logo` 资源键和 `m_color1`、`m_color2` ARGB；标志掩码经原 Shader 规则生成透明图像。夜间显示派生颜色与原值分开，品牌色不覆盖公司统计身份色、制式色或 Fluent 主题。自选图像保留自身 RGBA，不假设具有游戏掩码。

建筑总开关关闭时隐藏全部建筑；开启时，交通建筑（`transport`）、特殊建筑（`special`）和未分类建筑（`unknown`）始终保留，不受社会群体空选择或旧保存状态排除项影响，也不另设筛选入口。三类按解析器的原生 `category` 判定，共用 `semantic_colors.is_non_social_building`；功能容量分母缺失或实际人口为零只说明数值状态，不重新划定建筑类别。社会群体选项仅来自人口类建筑中实际存在的六阶层功能容量。三类建筑不是人口阶层，不为显示而补人口、补容量或制造缺失；交通与特殊建筑保留原类别颜色，未分类建筑按自身完整原生功能容量及综合、住宅、工作、休闲视图着色，缺失与零容量仍分别保留。建筑强调只改变颜色强度，不改变此可见性规则。

几何使用存档对象 ID 连接线路统计，运营和真实出入库区段分开；方向由站序与道路走廊匹配后确定。实际居民与工作人群在同一建筑按居民身份去重，与建筑数据菜单的功能容量分开保存。建筑数据菜单按阶层分配住宅、工作和休闲容量；住宅与工作容量包含游戏规则倍率及原生取整，休闲容量使用资产休闲值。选中阶层的各功能容量相加，使用全六阶层住宅、工作、休闲总容量中的最大值作为固定分母；不是实际人数除以占地面积，不随视口或阶层筛选重新归一化。缺少资产或规则数据时保留未知，零容量独立处理。地图显示等级由真实资产与实例车道配置映射，不是道路名称猜测。线网客流按存档模拟时刻在 23:00 起使用今日累计客流，此前使用现有信息页的平均客流；筛选、排序及染色同源。图例明确来源与存档日期，平均值不冒充该日期的单日观测。时刻未知、来源不可用或身份不唯一时保留缺失，不补零或改用另一来源；财务沿用现有周化估计。详细规范见[地图显示](requirements/map-display.md)。

单线预设的当日客流独立读取模拟自然日累计 `m_transportedToday`，保留今日口径，不跟随线网 23:00 前的平均客流来源。整条线路核定时间沿用现有重算结果；单边核定时间优先按保存站序的 `LineData.Stop.m_timeOffset` 取业务末站与起点的真实偏移差；缺失或无效缓存按同一存档原生道路距离、车型与停站规则逐段复算，独立记录段时长，不覆盖有效保存偏移，也不用全程或半程代替。所选方向长度按与原信息页相同的原生道路计数分段累计，保存重复经过的道路；下行空放只加入出库，上行只加入入库，全线各计一次。先累计整数单位，再通过 `display_rules.display_map_km` 转换一次，原始绘图几何不变。单边速度使用业务运营长度与对应核定时长，空放开关不能将额外距离塞入业务时间分母；全线速度用原全线里程与全线核定时间。原信息页全线里程及其他统计业务值保留，详见[线路指标](reference/line-metrics.md)。计划班次依据完整模拟自然日与原生星期掩码计数，包含前一时刻表日延伸至该日的发班。运营时间筛选按各原生时刻表实际首末发班分别判断，不填平停运间隔，不延长到末班车辆行程结束；时刻表未知和确认停运分开。

线网查询读取各筛选块已确认状态，各维度取交集、同维度多项取并集；未确认草稿不进入查询、预设或结果摘要。空选择为零结果，默认无客流边界与明确确认的 0 至 ∞ 区分，后者排除未知客流。结果数量来自同一查询快照，不按草稿或搜索候选重新统计。

地图盈亏仅分类周化净利润：收入、支出均可确认时，`abs(收入－支出) <= 支出 × 0.02` 为持平，边界包含；超出范围按正负分盈利、亏损。支出为零时仅净利润为零持平。缺字段、非有限值、非法支出或身份不唯一保持缺失，原利润金额不改写。分类由查询统一提供，筛选、列表状态和染色复用，详见[线路指标](reference/line-metrics.md)。

地图平均间隔使用原生班次和共享时刻表规则，默认日间；全天线路的日间排除夜间，非全天保留原自然日均值。高峰汇总存档所在周周一至周五早晚高峰的有效相邻间隔，按间隔数量加权；全日保留模拟自然日原均值。来源未知或班次不完整不回退其他模式。各时段、半开边界、停运间隔及连续色阶以[地图显示](requirements/map-display.md)为准，控件只选择口径。

规划的单功能视图保留同一建筑原始全功能、全阶层固定分母。建筑服务线路关系由原生 `TransportManager.ListLines` 对保存的固定点位置与站点网格查询，站点资产参数和保存的规则通过原生方法还原，默认查全公司；建筑序列化字段没有该列表。地图 schema 11 独立保存来源已知、完整性、真实空结果、未解析引用和未知。原生缓冲区饱和或链遍历保护触发时保留不完整状态，不将其记为完整空结果；技术诊断留在内部。显示层禁用不可绘制线路，保留完整原生关系及顺序，不以筛选子集改写服务来源。
