# 产品需求

本文件定义页面、筛选和业务边界；与[图表需求](charts.md)、[最新信息需求](latest-info.md)、[指标口径](../DATA_DEFINITIONS.md)共同维护。仍在使用的约定均是仓库规范，不按编写日期分级。

## 范围与数据

- CimStats 是 Cities in Motion 2 存档统计桌面工具，保留最新信息、地图显示、线路查询、公司、网络、城市统计及已有导出入口。不据示例截图添加虚构页面、评级、宣传说明或业务数值。
- 使用存档的模拟时间，不使用电脑时间计算统计日或周期。时间范围统一为 `[start, end)`，相邻区间边界不重复计数。
- 默认统计范围为上一完整模拟周；可选上一完整日和自定义。上一完整周是模拟时刻所在周一之前的七天，不是滚动最近七天。纯日期结束日包含该日，内部换算为次日 00:00。
- 小时、日、周、月粒度独立选择；已保存的合法设置继续沿用。自定义窗口无效时禁止应用，取消不触发查询。
- 历史不足保留真实缺失和不完整标记，不自动修改用户窗口、补零、插值或造未来时段。公司使用稳定 ID；空公司选择不是全部公司。
- 筛选、摘要、图表、提醒及导出读取相同有效快照。异步任务被新请求替代后不得显示旧结果；清空或换存档必须清理旧快照和导出可用状态。

## 输入方式

- 欢迎页、最新信息、线路和统计页统一支持鼠标、键盘、精密触摸板与触屏。触屏点按复用现有动作且只触发一次；移动超过系统拖动阈值后不再激活点按动作。
- 从滚动内容的图表、卡片、文字或按钮开始滑动，滚动最近的内容区；表格滑动距离按实际行／列尺寸换算，不能把像素当行数。编辑器内拖动保留文本选择，滑块、菜单和原生选择器保留自身手势。
- 图表触屏按住时显示与鼠标检查相同的真实日期、数值、单位与缺失规则；已缩放放大图的横向拖动平移当前窗口，纵向拖动可滚动所在页面。
- 静止长按使用系统长按时长，复用该位置已有右键上下文动作，且不附带普通点击；无上下文动作的控件不新增菜单。取消、多指、页面隐藏、失焦与目标销毁应清理待触发动作和按下／拖动状态。
## 启动与首次载入

- 启动页使用应用窗口大小，不覆盖整个显示器；默认窗口 1600×1000，按可用屏幕收敛，最小 960×680。正常启动先在同一个主窗口绘制实色 Logo 遮罩，完成首帧后才加载业务界面；Logo、欢迎页与业务页共享同一个原生窗口实例，不创建独立启动窗口或交接。遮罩与欢迎层使用相同背景、96px 标志及居中位置。
- 首次打开存档入口放在覆盖整个中央窗口的欢迎层中。标志从居中位置平滑上移，为“打开存档”按钮及简短 `.save` 拖放提示留出空间；不添加宣传或重复操作说明。
- 业务界面在遮罩下加载，欢迎层完整首帧绘制后以约 333ms 过渡露出打开入口，不设置最短停留或额外等待。系统关闭动画时立即显示最终欢迎状态，动画期间打开入口仍可用。
- 图表、卡片首次出现、页面切换及内容展开／折叠保持简短 Fluent 过渡；同内容 hide／show、窗口恢复及摘要选项切换不重播图卡入场，不变图卡和画布保持身份与图例选择；动画不能改变数据或触发查询，不增加装饰描边。尊重系统关闭动画设置，快速切换、反转与销毁后不得残留透明层或异常高度。
- 文件对话框取消后保持欢迎层；解析和图表准备仍由该窗口内的进度层覆盖。取消或失败恢复可重试入口，只有成功准备页面后才进入正常页面；不显示旧存档内容。
- 仅导入存档使用 Windows 原生打开文件对话框，使用系统自己的窗口外观，作为应用自有窗口共享自定义标题栏规则的例外；其他应用自有窗口保持共享标题栏。

## 统计页面和分析模式

公司数据、网络数据、城市数据使用同一个统计外壳。顶部文件操作、子选项卡和筛选区固定；下方数据区统一纵向滚动，不给每家公司设置独立竖向滚动，不产生整页横向滚动。

| 分析模式 | 含义 |
| --- | --- |
| 默认模式 | 各公司分别显示本期，不叠加历史周期 |
| 多公司对比 | 所选公司本期的同指标对比，不混入历史周期 |
| 同期对比 | 各公司分别比较自己的本期与对比期，不混入其他公司 |

三者互斥，选两家公司仍可处于默认模式。非同期模式提交空比较窗口，避免上次的比较状态污染图表或导出。对比周期支持上一等长区间、上周同期、上月同期和自定义，按现有历法规则计算；非自定义周期随本期调整，自定义周期保持用户设置。不等长窗口按相对时间对齐，悬停显示各自真实时间，不丢较长周期的数据，也不对不可比数据生成误导的增长提醒。

公司与网络页的多公司对比能力由当前存档中有效且去重的公司身份决定。少于两家公司时禁用该模式，鼠标、程序化设置和已保存设置都不能启动；替换为单公司存档时退回默认／总体。多公司存档勾选一家或取消全部选择不自动改变模式；单公司仍可使用同期对比。

### 公司数据

- KPI 顺序为现金流、公司价值、月票使用率、满意度、声誉、受欢迎程度。单公司宽屏一行六卡，双公司每栏 3×2；长名称保留完整悬停及辅助名称。
- 固定四图依次为现金流、公司价值、受欢迎程度、月票使用率，不提供额外指标选择器或图位交换。六项指标仍保留在 KPI 摘要中。
- 现金流允许集为 `trend-bar`时间柱，其余为 `line`趋势；单系列可有轻面积，多序列不强制面积，不提供重复折线／面积切换。满意度在 KPI 内保留速度、费用、质量维度，新设置默认速度；多公司维度和对应图布局保持同步。
- 默认及同期按公司分别布局；多公司对比采用公共图。窄宽度只改变布局，不改变模式、公司、指标或数据。

### 网络数据

- 保留总体、公司、同期三种分析视图及既有指标和能力限制。同期每张描述器只属于一个公司；公司数量不能把同期拼成多公司混合图。
- 摘要保留线路、设施、车辆、覆盖率（有可信口径时）、客流／出行量、换乘系数。车库／站点、平均／最大、客流／出行量开关只改变对应指标。
- 总体模式的“出行量”直接使用原生全市公共交通行程计数分子，跨公司换乘只计一次；不依赖选中公司数量或全集证明。总体换乘系数使用同有效时段的全市登乘次数与全市公共交通行程次数。两项不作同期或基准比较，其他指标的比较保留。公司模式及其同期视图保留公司参与行程口径，分类明细采用相应名称，不能展示为多公司联合去重行程。城市页全方式出行量与网络总体公共交通出行量分开。
- 多公司总体无空间去重依据时不展示覆盖率。车辆摘要名称始终为“车辆”；切换“平均／最大”只切换值，不新增备注、不改名。“最大”的值仍按当前所选公司线路的理论最大需求逐线相加，不能使用历史峰值替代；缺失需求不补零、不显示部分合计，真实零保留。计算口径保留在指标文档，不搬进卡片。
- 车辆历史趋势和分类条形始终使用平均运行车辆观测，不随摘要“平均／最大”切换。当前线路需求不生成环比／同期涨跌；XLSX 与摘要同值同范围并保留当前值上下文。
- 小时线路／站点只支持分类条形；其他允许类型以 `NetworkChart.allowed_modes` 为准。分类流量采用时间堆积／构成饼图，不增加两个都叫“趋势”的按钮。
- 分制式与分群体是同一总体的不同分解，不重复相加。缺失公司或分类不当作零；总量、占比和完整性按模型配对、同刻观测规则计算。

### 城市数据

- 使用全市历史，保留人口、出行、时间、方式、密度、经济和能源等既有指标及其切换能力。
- 人口取末有效观测；出行量为累计；出行时间使用可信分母加权；交通方式只有可靠同总体构成时才能作饼图。
- 道路／轨道密度、经济与能源按核实口径呈现，不编造 GDP、年化或现实货币单位。

## 线路查询时刻表

- 仅展示启用的时刻表内容：原始运行日掩码低七位均为零表示明确未启用，隐藏对应分组和记录；高位标志不改变星期判定。运行日缺失或无效继续保留“运行日未知”诊断，不归为未启用。
- 启用时刻表的零班次日组与有效午夜班次保留。线路没有可展示时刻表时显示“暂无已启用时刻表”，隐藏星期选择、摘要、图例及展开入口。
- 切换线路或清空时清理旧班次、选择、摘要提示及滚动位置。展示过滤不改原始班次、统计与导出数值。

## 最新信息与提醒

- 保留城市名称、模拟日期／星期／时间、人口与存档身份；缺失字段准确表示，不填示例城市或真实电脑时间。
- 核心和辅助指标分层呈现，不能为适配小窗口删掉既有指标或缩成难读文字。公司和制式筛选保留真实选择范围。
- 四类亮点、客流 Top10 和班次构成来自实际线路，空范围不填零、不伪造十条。排行／制式钻取和返回入口继续可达。
- 当日趋势使用模拟当天有效小时观测，当前小时可为部分观测；缺小时断线，不延伸未来时段。
- 公共交通分担率为全市模拟当日观测；总体换乘系数使用全市登乘与公共交通行程计数，公司筛选后的系数使用本公司登乘与参与行程。各自只累计分类完整、同时间且行程分母为正的当日观测；范围和缺少分母的限制需可查，制式筛选不改变行程分母。
- 关键变化提醒集中在最新信息页，不在统计页显示第二份提醒。保留原三类阈值及已读身份，不能无基准计算增长或凭颜色评价所有指标好坏。
- XLSX、分享和报告等动作随实际快照／文件可用状态启用；打开存档持续可达。

## 统一控件与验收

- 编号线路在完整存档的同一公司内按不同制式检查同号碰撞；除公交允许省略制式外，碰撞时显示“有轨电车1号线”等名称。不重号保留已有“路”或“号线”后缀，地铁和单轨纯数字名称始终补“号线”；真正自定义名称保留。过滤、首页与详情沿用同一显示身份，原始记录、关联键和数据导出名称不改写。

- 保持 PySide6、Fluent 控件和当前共享绘图架构。颜色、字体、分段按钮、图卡、菜单及弹窗使用共享组件，不引入另一套主题。
- 分析模式和图形能力互斥；图形切换只显示当前图表确实支持的选项，放大副本保留能力集、当前模式和分类显隐。
- 图卡、坐标、图例和单位对齐；长名称、长数值、负值、空数据、加载、错误、悬停和键盘焦点均需可用。
- 窄窗口允许顶部选项卡和控件换行，不能覆盖文件信息、导出或打开操作。实际运行验收需覆盖窄窗、紧凑图卡、放大图和 DPI 场景。
- 自动测试和视觉检查分别记录，不能以其他提交的通过记录代替本次验证。示例截图必须来自真实模型和实际控件，不能手工拼接不同分析模式的数据。完整检查项见[验收清单](../testing/acceptance.md)。

- 统计页全部非图表悬停（筛选、标签、数据卡所有子控件和头部动作）取消，动态刷新不恢复；辅助信息与点击功能保留，图表取值不受影响。

## 地图页面

地图为一级导航，完整行为与制图边界见[地图显示](map-display.md)。导航顺序为最新信息、地图显示、线路查询、统计数据。

单线完整目录、方向指标与线网组合筛选各守独立状态。线网六块筛选逐块确认，折叠摘要显示已应用条件和实际结果；显示／图层即时生效。客流来源、盈亏持平范围和平均间隔口径由共享查询统一，完整定义见[地图显示](map-display.md)和[指标口径](../DATA_DEFINITIONS.md)。设计要求同时维护需求、控件、数据定义、用户指南及验收，不以聊天协调记录代替仓库规范。
