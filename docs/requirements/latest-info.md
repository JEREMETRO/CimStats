# 最新信息需求

最新信息读取同一次解析得到的存档、线路和历史快照，不另外创建一套统计定义。共用[产品需求](product.md)、[图表需求](charts.md)和[指标口径](../DATA_DEFINITIONS.md)。

## 内容与范围

- 城市名称、人口、模拟日期、星期和时间来自存档；没有真实值时表示缺失，不使用电脑时间或示例城市。
- 公司多选和运输制式选择保留真实筛选范围；空公司选择不是全部公司。同名公司按稳定 ID 消歧，不能按显示名称合并。
- 核心、辅助指标分层，保持指标、数值、单位和范围可查。只重排布局，不因窗口变小删除指标、缩成难读文字或隐藏打开存档入口。
- 线路亮点、客流 Top10、班次构成使用有效实际线路。不足十条不补齐，空范围不填零。排名和制式钻取支持返回，并保持原筛选。
- 首页“客流结构”“班次结构”分布图显示正常数量，保留现有布局和比例表达，是小图常驻数字的唯一例外；不增加备注，不用悬停替代。其他线路环图、排行横条仍禁止常驻数字数据标签：隐藏环心合计、图例数值和百分比、条形尾数值，不将其挪到图卡头部继续显示。真实值及钻取身份保留，悬停承接原有数值，具体文案遵循用户确认后的统一政策。
- 预计配车来自时刻表重算；发班来自日期掩码和发班记录，不把城市 `trip-number` 当作发班次数。线路里程、运行速度、周化财务遵循[线路指标](../reference/line-metrics.md)。

## 当日趋势与对比

- 首页“净利润”显示为“周利润”，仍为所选线路周收入减周支出。
- `monorail` 在制式、图例、线路与报表展示中统一为“单轨”；旧中间数据中的“单轨列车”作为兼容别名读取，不改写解析字段和游戏参数键。
- 行车总时间为当日计划班次数乘各线路核定周转时间后求和；目前归一化数据字段名仍为“单程时间”，对外使用核定周转时间称呼。
- 平均核定速度为同一有效线路集合的计划运营里程合计除以计划核定时间合计，时间由分钟换算为小时，不再取线路速度的算术平均。里程和时间均按计划班次加权；缺任一字段的线路成对排除并标记不完整，零计划班次不参与。
- 首页平均间隔说明为“所选线路运营时间内的平均间隔”，计算仍使用已启用且运行日已知的各日组有效相邻间隔，不含跨午夜间隔；不同于线路详情的单日说明。
- 平均车公里人次保持人次/车公里口径，用于描述单位计划运营里程承载的客流；不据此推算人公里客运周转量或财务利润。

- 当日是存档模拟当天；只读取有效小时，当前小时可有部分观测，缺测断线，不延伸到未来。
- 全市公交分担率使用同一模拟日的城市观测，不能把某公司的筛选结果冒充全市分担率。
- 换乘系数为配对客流与出行量之比，缺分母不可算；聚合先汇总有效配对数量再相除。由于历史分区出行量缺少制式分母，即使选中某制式，换乘系数也保持所选公司的全部制式，不随制式筛选；`scope`与 `reason`必须说明这一范围，不能让用户误认为是单制式系数。
- 同期和公司身份图例共用 `SeriesLegend` 色柱；支持的图形、放大和导出遵守同一契约。

## 提醒与动作

- 关键变化提醒只集中在此页，保留已有三类阈值配置与已读身份。提醒基于可比的有效基准，不对历史不足、不等长不可比窗口或缺分母数据计算虚假增长。
- 不把颜色和领先／落后统一解释为经营好坏；百分点与相对百分比区分。
- 读取失败、取消、换存档、清空时不得保留可导出的旧快照；新的异步请求替代旧请求后，旧任务不能覆盖新结果。
- XLSX、图表、分享和报告动作仅在相应快照或文件可用时启用；导出与屏幕使用同一份有效结果。
