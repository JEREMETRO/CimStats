# 图表与对比模式需求

本文件适用于公司、网络、城市及最新信息中实际存在的对应图表，包含普通图卡、放大图和 PNG 导出。组件规格见[视觉设计](../design/visual-design.md)与[控件契约](../design/controls.md)。

数值按[指标口径](../DATA_DEFINITIONS.md)在界面和导出边界向零截断：最多两位小数，平均运行车辆数最多一位。放大摘要卡按数值、单位及间距的实测最小宽度布局；单卡和多值卡均不得通过固定宽度裁切数值或覆盖单位。

自动坐标轴的单位和步长必须适应上述小数位限制，使各个刻度文字可区分；“万／亿”缩放掩盖细小差异时使用较细单位，极小区间至少采用显示精度可表达的步长。刻度按十进制网格生成，不能因二进制浮点误差将 0.8 标为 0.7。真实数据、轴坐标映射及显式 `AxisSpec` 的范围、步长和单位保持原口径，不通过增加显示小数位或提前截断数据修正刻度。

## 分析模式

- 默认模式只显示本期；多公司对比只比较所选公司的本期数据，不叠加历史周期。
- 同期对比按公司分别出图，只显示本公司的本期和对比期；不在一张同期图里混入多家公司，因此每个日期只有本期、对比期两组柱。
- 选择公司数量不等于切换分析模式。图表、摘要卡片和导出必须使用同一份查询结果，不能为了截图拼接不同模式的数据。
- 多公司对比只在存档中有至少两个有效公司身份时可用，不能以当前勾选数量禁用多公司存档的模式；单公司可使用同期对比。

## 配色与图例

- 多公司柱图恢复既有稳定公司配色；多分类堆积柱保持分类色相，同时用公司色阶区分不同公司。
- 同期保持同色相的本期深色、对比期浅色；折线同时保留实线／虚线区别。对比不只依赖颜色，图例必须写明实际公司或周期名称。
- **同期色柱图例必须与公司对比图例共用 `SeriesLegend`，使用同一个尺寸、字体和排列规则。** 多分类图例显示实际分段色柱，单系列显示实际系列色柱；颜色及透明度直接来自对应图表数据。
- 同期图例标注“本期”和实际对比周期名称，不用“左／右、上／下、实线／虚线”的位置说明替代色柱图例。
- 共享图例规则同步到时间柱、堆积柱、横向条形、折线／面积和实际支持同期的饼图。没有对比数据的图表不生成虚构的对比项。
- 普通图、放大图和 PNG 使用同一套配色及图例。分类显隐不修改查询值或分母；隐藏所有分类后保持空选择。

## 柱形与文字

- 恢复原版两端圆角柱及同色相轻微明暗效果。堆积柱仅在整柱外轮廓圆角，分段边界不各自圆角。
- 分组柱宽上限：普通图 20、放大图 48；组内间距依原版公式随时间槽宽度计算，上限分别为 4、24。横向条形高度上限为 14。
- 坐标、单位与普通标签使用微软雅黑 UI 12 逻辑像素；放大图分段数字为 13，合计为 Segoe 强调字体加粗 15，按原版可读下限适配空间。紧凑分类图例为 11。
- 放大堆积图同时显示每段数值与整柱合计，不能因小分段而丢失合计。0 是真实数值，应显示数字及零值标记；缺失值不得当作 0 求和。
- 所有小图禁止常驻数字数据标签，包括折线、分组／堆积柱、横向条形、环图中心合计及图例数值／百分比。适用于公司、网络、城市和最新信息，单系列和稀疏时段也不能例外。坐标刻度、日期、分类名、标题与身份图例保留；悬停接口继续提供真实值，具体内容按确认后的统一文案政策维护。
- 紧凑 PNG 与小图采用同一规则；放大图继续保留数值标签和摘要。车辆图始终展示平均运行车辆历史，摘要选择最大需求不影响图形数据。

## 放大与响应式

- 公司、网络、城市、最新信息的所有放大图在当前应用窗口内展开，占用当前窗口可用区域，不新建可单独关闭的窗口，不改变主窗口大小。绘图区、摘要及详情外框下铺共享的不透明白色衬底；透明画布不能露出灰色或黑色背景。
- 放大标题栏常显带 Fluent 收回图标的“缩小”按钮，支持鼠标及键盘且点击目标至少 32。点击或 Escape 在同一窗口收回详情并返回原图，恢复来源焦点与原页面状态；窗口系统关闭仍关闭应用。打开保留当前类型、能力集和身份，返回与再次打开保留分类显隐，包括全部隐藏；查询值与分母不改变。
- 展开从原图位置平滑扩展到当前内容区域，缩小沿原位置收回；过程中可中断，不添加等待或触发查询。复用共享动效开关，Windows 关闭动画时立即到最终状态。当前窗口 resize 时详情同步适配；来源隐藏、销毁或数据替换时清理详情及动效，不回传旧选择到新快照。
- 放大图恢复分公司／分时段摘要卡片；移除下方数值表和操作说明条。
- 紧凑图例可缩短分类名，完整名称保留在悬停和辅助名称中。190 高图卡在窄宽度下仍须容纳绘图区与日期标签，不能只验证控件外框没有越界。
- 窄窗口允许统计子选项卡换行；标题、文件信息、导出和打开存档按钮不相互覆盖。

## 验收

回归测试至少覆盖公司颜色区分、实际单公司同期分组、所有支持的图形及其放大副本、图例与绘图颜色／透明度一致、小分段和负值标签、全分类隐藏、400×190 图卡和 960×680 主窗口。截图采用程序实际的数据模型，演示数据不成为业务默认值。
