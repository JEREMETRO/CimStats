# 地图显示

地图是独立一级页面，导航顺序为最新信息、地图显示、线路查询、统计数据。沿用现有 Windows 标题栏、共享页头、存档信息、导出、打开存档和 Fluent 主题，不包含统计子选项卡或左侧地图二级导航。

## 制图和真实数据

苹果地图的分层、低饱和底图和随缩放增加细节的表达用于二维北向地图；应用外壳仍完全使用 Fluent。地图只画可信的道路、真实路口连接、建筑、站点和线路。空白不解释为水体，不臆造绿地、地名或连接线。

道路的地图呈现等级由实际资产类型和保存的车道配置共同决定，独立于单行、公交专用、停车、路肩与桥隧属性。轨道单独绘制；快速路属性优先；大道对应主干；普通道路再按真实双向总车道数区分主干、次干和支路；未知类型保留未分类。该分级是制图映射，不宣称游戏保存了主干、次干等行政等级。像素符号宽度不冒充实测道路断面。路口只能使用游戏真实连接曲线；不能用假圆盘或路口中心直连填补缺口。

道路按等级、缩放和高程调整主体与细描边，交叉口同高程描边先画再填芯。路口宽度沿真实连接曲线衔接相邻道路，桥隧边缘连续，不使用胶囊形端框。公共交通颜色强于底图，不自动绘制方向箭头；圆角转折和有限共线显示偏移保持原始路径及里程不变。空间索引、视口裁剪和标签避让限制全城尺度噪声。

## 单线与目录

单线、线网、规划三种预设共用地图画布，各自保存查询、视角和面板布局。主窗口的预设选项卡与统计数据使用相同的共享标题栏位置、控件、字体、尺寸、间距、选中指示和动效；窄窗口沿用标题栏的换行行为，页面内不重复显示。独立使用地图页面时保留页面选项卡。地图左上搜索面向完整可用线路目录，选择后进入单线线路信息，不受当前线网筛选排除；所有预设及尚未选线、加载中、清空存档状态均默认只显示搜索按钮，鼠标悬停或点按展开，输入或选择结果期间保持展开。线路查询详情的“地图上展示”以当前存档和线路稳定对象身份跳转，切换存档后不接受旧身份。

所有地图线路列表共用完整存档目录的显示名称解析器，默认单行“制式＋线路名”；仅同制式、同名而跨公司冲突时加共享规则解析后的公司名。名称不含对象 ID 或客流第二行，筛选和建筑菜单切片不重新判定冲突。业务选择仍以原始稳定对象 ID 为键。回车提交搜索，唯一可用结果可定位，多项结果由高亮选择确认；加载中提交保留当前存档身份，切换存档后不消费旧搜索。

预取期间的搜索请求以当前输入路径和工作代次绑定；统计结果接管同一预取输入时保留请求，取消或打开新输入时废弃。空输入、清空及无匹配时移除旧结果，回车和搜索按钮共用一次提交入口。单线信息面板的小搜索只在搜索时展开结果，选择后收起；线路列表标签提供常驻目录，其他多选目录保持可连续选择。

单线右侧一级标签按“线路列表”“线路信息”排列，无当前线路时默认显示列表；已有当前线路时可保留信息标签。线路列表始终可回访，使用完整存档目录，不受线网筛选影响。常驻列表支持按制式、名称、开线时间、客流和班次升降序排列；名称采用自然数字顺序，同值按自然名称稳定排列，缺失和无效数值始终放在末尾，零保留为有效值。客流按存档模拟时刻的 23:00 界线选择今日或平均客流：23:00 起使用今日客流，此前使用平均客流，与线网筛选及染色同源。班次使用完整的当日发班数；排序不自行重算或补齐元数据。重排保留搜索、当前线路及可见位置，不发出线路选择或改变地图视角。选择线路进入信息，信息保留小搜索和两类数据，不常驻重复的大列表。切换这两个标签不重读存档、不重建地图索引、不改变地图中心或缩放，选择新线路时才定位。两个面板均支持现有浮动、折叠与恢复布局，兼容仅保存线路信息面板的旧布局，保留预设查询和视角。

单线预设默认显示往返线路上行，可选下行或双向；双向以下行实线、上行虚线区分。环行与单行保留完整路径。顶部提供全目录线路搜索、稳定身份选择、方向与空放操作；侧栏数据只分“线路信息”和“客流数据”两类，以紧凑名称－数值行呈现。线路长度、核定时间和核定速度放在一起，位于站点数之前，车库和开线、改线日期位于该组之前。方向长度与信息页、报表的原生地图里程来源一致，通过共享入口转换一次，不使用绘图曲线的长度替代。上行、下行的核定时间采用相应起站至指定末站的保存到达偏移之差，速度使用与该时长对应的运营区段长度；缺少可信站点偏移时显示“—”，不以全线时长平分或回填。字段标题标明上行、下行或全线，单向视图隐藏原全线地图里程行，仅双向及完整环行、单行保留全线信息；全线核定时间和速度保留线路信息页原字段及可用性规则。空放选择按数据接口的真实库段调整显示长度，不将空放里程除以未包含空放的运营时长；客流和发班保持原有整线口径，“当日发班”不带“计划”括号。其他字段及数字使用线路信息页共享格式与截断规则，零与缺失区分，缺失显示“—”。

## 规划与建筑服务

规划预设增加已有线路的搜索、多选和比选入口，不创建线路，不提供命名、保存或管理方案。选中线路与建筑菜单共用选择集合。建筑强调默认开启，选中线路不会自动关闭。社会阶层筛选可结合综合、住宅、工作、休闲功能视图；切换功能只改变呈现分量，保留原始完整分母。

建筑点击打开可搜索、逐项选择、全选与清空的服务线路菜单。关系来源为游戏原生 `TransportManager.ListLines` 即时查询，使用存档固定点位置、原始站点网格、实际站点资产参数及保存规则；建筑对象并未保存该列表。默认使用原生支持的全公司查询，保留原生顺序与稳定线路身份，候选不随当前线路筛选改变，不推断本地玩家。可解析线路按完整目录名称显示，可命名但无可绘路径的线路禁选；原生关系不因地图显示能力而删除。

来源已知、完整、真实空结果、未知、未解析引用及原生截断分别保留。悬空引用不构造无真实名称的线路条目；部分可用结果仍可选择，必要时只显示“部分线路不可用”。来源未知或全部不可解析时显示“线路信息暂不可用”并禁用选择，只有完整且确实零服务关系时显示“无服务线路”。技术诊断和引用 ID 仅保留内部，不显示额外悬停提示。

## 方向与站点

先分离真实出入库路径，再以反向站序和道路走廊匹配识别上下行；道路匹配包含高程。总站至终点为下行，返回为上行。仅末端回转区域内几何近似同分的候选可以按特殊站名消歧，沿途特殊名不覆盖明确终点。往返不成立时继续检验运营路径闭合，区分环行与单行；缺失、损坏几何不当作正常单行。

三个模式固定为“整条线路显示”“仅显示环行与上行线”“仅显示环行与下行线”。三个模式都保留完整环行和单行运营路径，不提供单行显示开关。水上巴士缺乏可确认的运营路径，本期地图不提供其线路显示、筛选与排序入口；已有线路查询和统计保留原数据。

标出站点独立且默认开启，站点名称和线路编号各自控制；隐藏站点仅暂停名称绘制，保留其设置。切换到客流或平均间隔染色时默认关闭站点显示，之后允许手动重新打开；保留站名偏好，隐藏站点时暂停站名绘制。站点至少关联一条当前实际显示的运营方向才绘制；关联线路或方向全部隐藏时，站点及站名一并隐藏，共享站在仍有可见方向时保留。

## 线网筛选

手动、公司、制式、盈亏、客流和运营时间六类筛选入口可见。维度之间取交集，同维度多项取并集，空手动选择保持空结果。线网客流按存档模拟时刻选择来源：23:00 起使用今日累计客流，23:00 前使用现有线路信息页的平均客流。筛选、排序和客流染色共用这一数值；来源与存档日期明确显示，平均客流不标作某一日的观测。时刻未知、字段缺失或身份不唯一时保留缺失，不补零，不改用另一来源。真实零值仍有效，原始昨日字段保留。盈亏沿用线路周化收支估计，区分盈利、亏损、持平和缺失。收入与支出均可确认时，净利润绝对值不超过支出的 2% 归为持平；超过该范围按正负区分盈利、亏损。支出为零时只有净利润为零归为持平。筛选、列表状态、地图染色共用判定，仅改变分类，不改写原始或周化利润数值；字段不可用、非有限数或身份不唯一时保留缺失。

面板“已选”与底栏共用所有筛选条件交集后的实际结果数量；筛选排除线路时保留原来的手动勾选，取消筛选可恢复这些线路。显示数量不额外执行查询或重建候选目录。

线网的公司、制式、盈亏、客流、运营时间和手动线路筛选分别可展开、折叠。编辑只修改该块草稿，点击该块“确定”才应用并自动折叠；一次确认不能应用或丢弃其他块尚未确认的选择及输入。搜索只检索候选目录，手动全选、全不选仍需该块确认。按钮宽度按共享字体与 Fluent 实际内边距测量，搜索框使用剩余空间；最窄面板也须保留完整按钮文字及可点击区域。查询、预设和地图只读取已应用状态，显示设置和图层操作保持即时生效，程序化恢复状态仍为静默恢复；全局重置清除草稿并恢复全部线路及默认筛选。

每块标题左对齐，展开／折叠箭头右对齐；“盈亏”标题不带周化估计等后缀。标题下方显示该块已应用的筛选标准及所有条件交集后的结果，例如“周三17:00-18:00 已选：22条”，省去“筛选区段：”前缀；可用宽度足够时保持一行，放不下才自然换为两行，不为长文字预留多余空白。跨日区间标明终点星期，跨周长区间保留实际日期。未设置条件或恢复不限时摘要空置，确认得到零结果时显示 0 条；未确认草稿不进入摘要。结果数量与顶部、底栏一致，不因搜索候选或折叠状态变化。

客流范围提供独立的下限、上限输入和双端滑块。下限最小为 0，滑块有限部分采用平方幂函数，归一化位置 `t` 对应 `50000 × t²` 人次，使 5000–15000 落在中间且比线性映射占更宽的操作范围。50000 是最大有限值，最右侧另留独立 ∞ 档，可用方向键相邻切换；无上限保存为缺失边界 `None`，不伪造有限最大数。输入沿用共享两位截断规则，精确值不被位置映射覆盖，移动一端不改写另一端的手输精确值。默认未筛选时界面显示 0 至 ∞，已应用下限仍为 `None`；明确确认数值范围后，缺失客流不能按零混入。倒置或无效范围不能提交。客流口径从查询提供的来源及日期读取，界面仅显示实际日期或“平均客流”，与该块“确定”放在同一行、口径左对齐，不再追加“客流”“人次”等说明。筛选值与列表排序、线路染色使用相同来源，不另取或补值。

线网增加时刻表运营时间筛选，可查模拟日期中的时刻或时间区间。开始、结束各有独立的标题及输入区域，下面使用全宽时间滑块，不挤压或遮盖输入；星期轴端点文字、拖动柄与刻度各占独立高度，不能相互覆盖；窄窗口与不同 DPI 保持布局分离。时刻模式禁用结束边界并保留有效区间偏好，无效时段不能确认。按每段时刻表首末发班确定运营时段，末班之后不因车辆仍在途而延长；保留停运间隔、跨午夜时刻和原生星期掩码。未知时刻表不能视为全天运营。该筛选与其他维度取交集。

实际切换进入客流或间隔数值染色时，默认隐藏站点，保留站名开关的已有偏好，并作为一次显示状态变化应用。用户可随后手动重新显示站点；同色重复设置、数据刷新、程序化恢复及同一色阶内的统计模式变化不再强制隐藏。

运营时间使用星期轴和时间轴，时间轴上方可手输时分并双向同步。星期以模拟日期所在周的周一为锚点，周日跨周一延续至下一周；同星期终点时刻早于起点时刻表示次日，跨午夜高亮轴两端。星期选择只锚定实际查询日期，不改写线路保存的运行日掩码。

## 染色与排序

六种染色为按制式、按盈亏、按公司、每条线路独立配色、按平均间隔和按客流。不提供线路类型染色或占位入口。地图叠放排序按客流、制式或公司独立设置，高优先级最后绘制；制式和公司拖动顺序分别保存，组内按客流、线路号和对象身份稳定排序。排序不会修改筛选或颜色。

平均间隔染色下设二级下拉菜单，仅该染色选中时显示，选项为“日间平均间隔”（默认）、“高峰平均间隔”和“全日平均间隔”。保存并恢复所选口径，切换时直接更新颜色，不改变筛选、线路排序、真实几何、地图中心或缩放。口径仅由该下拉选项表达，图例不增加日间、高峰、全日或保存周说明，不新增工具提示、脚注或其他解释文案。

日间对完整原生班次按现有共享时刻表规则确认的全天线路，排除夜间 00:00–05:30 的班次间隔；非全天线路保持原自然日均值。高峰汇总存档所在周周一至周五的真实相邻班次间隔，只取早高峰 07:30–09:30 与晚高峰 17:00–19:30，按有效间隔数量加权，不取每天均值的简单平均，不使用周末班次替代。两个端点及整个间隔必须落在同一半开时段内，不跨早晚高峰或日界连接；保留同刻真实班次的零间隔，排除 ≥180 分钟的停运间隔。星期掩码未知、班次不完整或没有足够班次时为缺失，不退回其他口径。

全日平均间隔保持原口径，取模拟自然日完整原生班次经共享 `prepare_schedule` 算出的数值分钟，包含前一时刻表日延伸至当日的发班；重复原生身份去重，不合并不同身份的同刻发班。运行日未知、班次不完整或原生时刻无效时为缺失，不解析格式化的间隔文字。数值班次数与开线日期通过完整线路目录传递，分别保留零与缺失、原始日期时间。

两种数值染色在代表锚点之间连续插值 RGB，不在范围边界跳变。平均间隔的代表锚点为 5 分钟血红、7.5 分钟鲜红、12.5 分钟鲜橙、17.5 分钟黄、25 分钟黄绿、37.5 分钟绿、45 分钟深蓝；≤5 和 ≥45 在端点饱和。原 15–30 分钟黄色拆为 15–20 黄色与 20–30 黄绿色，小间隔血红、红、橙保持鲜明区分。高峰使用独立连续色阶：≤3 分钟黑红，3–5 红，5–8 橙，8–12 黄，12–18 黄绿，18–25 绿，≥25 蓝；代表锚点为 3、4、6.5、10、15、21.5、25 分钟，端点饱和。日间与全日继续使用上述原间隔色阶。客流的代表锚点为 1000 人次蓝、3000 绿、7500 黄、15000 橙黄、25000 橙红、40000 红、50000 血红；≤1000 和 ≥50000 在端点饱和。缺失为独立灰色，真实零取对应低端颜色。紧凑渐变图例与地图及导出共用解析器，标注平均间隔的分钟、客流的千人次刻度、客流来源和存档日期；图例只显示颜色锚点对应的单数值刻度，不显示区间或 ≤、≥ 标签；刻度沿现有连续渐变坐标定位。日间与全日的分钟刻度为 5、7.5、12.5、17.5、25、37.5、45，高峰分钟刻度为 3、4、6.5、10、15、21.5、25，客流的千人次刻度为 1、3、7.5、15、25、40、50。每个刻度处的颜色必须与同一数值经颜色函数求得的结果一致；标签与短刻度共用位置，不改变真实业务数值、连续插值或端点饱和。

显示设置允许分别调整存档中实际交通制式的线路粗细，按稳定制式键保存，不修改真实道路宽度或线路里程。整条上下行线路同时显示时，可独立选择以不同线形区分：下行实线、上行虚线；单独显示一个方向时采用连续实线，环行与单行始终保留完整实线。线宽和线形不改变筛选、配色及方向判定。

“计入空放里程”默认关闭，仅改变地图里程范围；有真实可识别空放路径时才淡虚线显示，不改变客流、收入或盈亏。

## 建筑与配色

建筑按所选社会阶层显示，色相表示该建筑对该阶层的实际功能，深浅表示密度；阶层筛选与功能染色不是互斥模式，不能直接用阶层基色代替功能色。功能关联、密度尺度与多阶层合成遵循经核对的 CIM2 数据菜单口径，不以资产用途或人数除占地面积的猜测替代游戏定义。混合建筑保留各阶层及功能的关联，按建筑和居民稳定身份去重。交通、特殊及未分类对象独立；缺失与已知零分别保留。

提供建筑强调选项。自动默认依据实际可见的运营线路：没有线路时强调建筑密度深浅，有线路时降低底图对比。线路总开关、制式图层及组合筛选造成空结果时均按无线路处理。用户手动选择强调或弱化后保留选择，重置可恢复自动默认；强调仅改变视觉强度，不改变功能色相、密度值及图层筛选。

名称、顺序、基色和缺失状态来自共享语义配色注册表。建筑低饱和色和强度变化由基色派生。用途延续住宅绿、商业蓝、工作红、混合紫、交通黄；社会群体保留城市页的既有色义，制式保留网络与首页的既有映射。公司配色从完整存档稳定身份集合建立，不按筛选后的列表位置重新分配。图例、结果、地图与导出使用相同解析器。

## 面板与窗口

三个独立面板默认合并为右侧 360 像素标签组，一次展示一个。可拖出为主窗口内部的浮动面板、调整大小、固定位置、折叠为标题条并拖回停靠；不创建窗口外浮动窗。固定禁止拖动和缩放，仍能折叠。停靠组可整体收起为窄标签条，提供恢复默认布局。布局变化不改变查询、地图中心或缩放。

布局持久化，窗口缩小或 DPI 改变时限制浮动面板在可见范围。控件与排序条目拖动不触发面板拖动，面板滚动不平移地图。1440×960 核心控件完整可见，960×680 可滚动访问，无文字截断或不可恢复遮挡。禁止擅自新增悬停提示、开发说明、算法状态和占位文案。

面板标题由同一中文解析器生成，标签、浮动标题与折叠窄条均不得露出预设内部键。用户折叠与展开复用共享 `CollapseMotion`，浮动面板保持展开尺寸并在当前位置恢复；恢复布局、隐藏和关闭系统动画直接应用终态。动效不修改筛选、地图中心或缩放。搜索框及结果列表在加载、焦点和悬停时保持 Fluent 不透明背景。

左上搜索统一默认收起为搜索按钮，鼠标悬停展开，点按或键盘激活按钮进入输入；输入、内部按钮或结果选择持有焦点时保持展开，鼠标离开整个搜索及结果区域且失焦后收起，保留查询文字；选中结果后收起。筛选更新与同一预取输入的统计接管不打断当前输入，换存档或取消加载清除旧结果并恢复按钮。数值图例使用完整连续渐变条及颜色锚点对应的单数值刻度，标题、单位、来源日期与独立缺失色同屏可见，并避开比例尺和缩放按钮。

所有地图图例在地图下方的独立区域绘制，不覆盖道路、建筑和线路。图例高度由当前宽度、字体与 DPI 按共享绘制规则计算，地图使用扣除图例后的实际绘图区，两者无间隙且不相交；空图例不占高度，切换存档或取消加载清除旧图例及日期。数值图例与普通身份图例均采用这一布局，普通图例保留最多两行的既有规则。搜索结果、缩放按钮、加载条与比例尺依据实际绘图区定位。改变图例、宽度或 DPI 保留用户中心和缩放，不再次自动复位；首数据仍按原规则定位。

## 数据流与验收

独立不可变几何与查询快照，通过存档稳定对象身份连接统计。后台提取支持取消和过期丢弃；正常使用不读写持久化地图快照缓存，只复用当前存档的内存快照与绘制帧，不删除已有缓存文件。筛选、染色、排序和面板操作不重读存档。生产代码不读取实验目录，不修改游戏存档。

正常打开存档时并行启动真实地图解析，与统计解析共享当前输入身份但不互相等待；隐藏地图页也完成解析。统计结果就绪后接管同一预取任务或快照，进入地图不得再次解析同一输入。切换、取消或统计失败时取消旧预取，旧结果不能覆盖当前存档。尚未完成时保留加载动画，首个当前视角完整帧就绪后结束；零尺寸视口或空图像不属于完整帧，也不能导出，恢复有效尺寸后重新准备。实际冷解析是加载验收依据，持久化缓存命中不能代替。

应用启动页期间，通过现有后台导入任务提前准备无 GUI 副作用的地图几何与查询依赖，不在该任务创建窗口、字体、主题或图像控件，不为未指定存档延长欢迎页等待。已有明确存档路径后，地图与统计解析并行启动，查询统计准备也在后台完成；启动首帧、可操作时刻和正常打开的各准备阶段分别记录，不以移动等待位置冒充提速。

独立方向分析使用有界并行，结果须与串行算法一致；取消时结束子任务并清理临时传输文件。隐藏地图页提前准备首屏，准备完成后打开菜单直接呈现当前完整帧。

隐藏页面预热与可见页面复用同一地图／图例布局，帧尺寸使用实际绘图区，不把地图几何重新设为包含图例的整个表面。图例区域与地图 PNG 追加的图例共用绘制器，导出总尺寸为实际绘图区加图例高度；不得用白底覆盖原绘图区来伪装外置，也不新增解释文字。

大地图的完整图像在后台绘制，界面线程仅呈现帧、响应输入和绘制固定图例。平移与缩放可暂时变换上一张同查询帧，随后替换为精确新帧；筛选变更不复用旧查询内容。道路与建筑允许缓存视口周边图层，但必须按几何、图层选项、颜色、缩放、尺寸和DPI失效。视口外路径只省略绘制工作，不删改实际线路、站点、方向或里程。性能验收记录相同存档、窗口、视角的冷/热读取、绘制耗时与交互响应；测试通过不能代替实测。

浅色底图采用与现有Fluent外壳协调的中性微冷灰白，保留白色街道、淡黄色高等级道路与清晰边界。只调整地图底色及道路建筑描边，不改变共享制式、公司和建筑功能的颜色含义，应用外壳继续使用共享Fluent令牌。

验收包含 30 条既有样本、503E 第十四站、两条 5P 单行、环行、平行返回、小环、重复站和桥隧；建筑关联去重、密度比例、缺失与零；筛选、颜色及真实叠放；浮动固定折叠停靠与持久化。最终以同一真实存档分别检查三个预设的 1440×960 和 960×680 完整窗口；线网还须在相同视角、缩放与筛选下切换右侧三个标签，检查布局与可达性；960×680 分别核验真实 DPR 1.25 与 2 下的筛选标题、条件摘要、50000／∞档位及跨午夜输入，记录实际设备像素比。控件测试或合成截图不能代替真实窗口验收。

正式启动的异步页面创建流程与同步流程保持相同四页顺序。地图提取脚本及资产分类、轮廓元数据随包提供；查询筛选按存档恢复，新存档不继承上一存档的盈亏或客流条件。

提取及首帧准备期间，地图画布顶边显示 Fluent 不定进度动画；完成、失败或切换存档后清除。动画不改变地图范围，不附加开发说明或悬停提示，读取失败后允许重新进入页面重试。

方向筛选同时控制对应运营区段的站点：上下行分界站属于两方向，其他站点仅在至少一个当前可见运营区段与其关联时显示。环行与单行保留完整运营站序；同一实体站在另一条可见线路上仍被服务时保留。道路与线路连续性必须在街区尺度核验真实路口连接，不能仅以全城截图验收。

加载响应验收覆盖从打开存档到地图首帧的整个过程，同时记录界面事件间隔及统计、几何构造和绘制阶段。Python 后台计算按高精度单调时间预算定期让出执行机会，长线路内部仍检查取消；后台绘制不访问窗口控件，界面绘制不执行等待。保留 Fluent 加载和过渡动画，业务数值与原始几何不因调度优化改变。

正常地图接管时，线路自然日和工作周统计在后台准备。输入为独立复制的原生数值、可用性及班次身份字段，保留未知班次与真实重复身份规则，不复制无关车辆载荷；后台不读取控件。任务带存档身份、代次和任务身份，取消或切换存档后不接管旧结果。统计准备完毕后按最新已应用筛选与待消费搜索安装完整查询，不用缺失或零占位覆盖真实颜色。显式快照设置仍支持同步调用；端到端回归覆盖正常异步入口，正常加载诊断另记输入捕获、统计计算和接管耗时。

地图导出只在当前快照、图层选项、视角、窗口尺寸和 DPI 对应的完整帧就绪时可用。平移缩放时临时变换的旧帧、切换存档后迟到的旧帧以及准备失败均不能启用导出；空地图不导出。绘制失败同时匹配查询与视角，旧视角的迟到失败不阻止当前视角继续准备。

画布支持独立图例条，公共测量与绘制接口共用现有刻度、字体、颜色和缺失项；外置图例时，地图视口内不绘制或预留图例位置。导出按当前地图视口尺寸先绘制地图，再在其下方追加独立图例条，总尺寸由画布统一提供；地图区域完整保留，图例不覆盖任何地图像素，也不改变地图中心、缩放或完整帧可用条件。空图例不增加导出高度，通用图例保留最多两行及原有省略规则。
