# 视觉设计

采用现有浅色 Fluent 桌面样式；本文件归并有效的设计、控件、图形与布局预算，不保留重复派工或其他提交的通过记录。

## 样式入口

颜色、尺寸来自 [stats_tokens.py](../../frontend/stats_tokens.py)，字体来自 [stats_typography.py](../../frontend/stats_typography.py)，主题及共享控件消费同一来源。单位均为逻辑像素，不以截图设备像素替换，不混用 pt 与 pixelSize。

| 语义 | 基线 |
| --- | --- |
| 页面／表面／边框 | `#F4F8FC`／`#FFFFFF`／`#E3EAF3` |
| 文字／辅助文字 | `#18314F`／`#65758B` |
| 控件强调／公司数据主色 | `#0067C0`／`#1677FF`，第二公司 `#00A67A` |
| 字体 | Microsoft YaHei UI；正文 14，辅助／坐标 12，图标题 14，KPI 21，页标题 29 |
| 最新信息数字层次 | Segoe 强调字体；中型 KPI 数值 600，最大核心数值 700，标签／单位 400；保持既有字号和完整数值 |
| 圆角 | 控件 6，图卡／KPI 8；已有大表面 12，不嵌套重复边框 |
| 间距 | 页面约 20、板块 16、内部 12–16、关联控件 8；图表头部和内容使用共享间距 |
| 图标 | 线性 Fluent 图标；图表动作 16，导航约 20，点击宿主至少 32 |

公司颜色表达稳定身份，不代表好坏；选择子集不能重新分配其他公司颜色。不得全局给每个 QWidget 或 QLabel 涂白背景，样式按语义组件边界应用。

放大图以共享 `CARD_BG` 白色绘制详情窗口及图卡表面，不保留紧凑图卡边框；透明绘图画布、摘要间隙及外框都落在不透明白色衬底上。白底只应用于详情窗口和图卡边界，不给所有子控件重复铺底。标题栏保留可见的“缩小”图标文字按钮，普通尺寸与最大化均须检查。

## 图形

- 共用绘图画布，不加图内第二层框。线宽 2、轻网格 1；趋势轻面积基线透明度 0.10，阴影低于数据层，不密集绘制永久圆点。
- 缺失断线，不补零、不平滑改写观测；负值保留零基线。hover 显示实际公司、指标、周期、真实日期、单位与数值。
- 同期浅色透明度基线 0.45，折线同时用虚线；公司比较以稳定色阶区分。普通、放大、PNG 共用颜色与身份图例。
- 圆柱、组宽与间距、放大分段标签、整柱合计及摘要卡片的精确约定以[图表需求](../requirements/charts.md)为准；不得以早期稀疏柱宽建议覆盖已恢复的公式。
- 小图不绘制常驻数字数据标签，环图中心与图例数值也在此范围；放大图保留分段／合计及摘要。子选项卡、线路亮点悬停不增加边框，键盘焦点与鼠标状态分别处理。
- 同指标、同窗口的可见公司使用可比量程与刻度；同期量程覆盖两个周期。隐藏分类不改变分母，全部隐藏保持空选择。

## 布局预算

标题／文件区、子选项卡和筛选固定；下方仅数据区纵向滚动。公司单视图六 KPI 与四图位；双公司每组 KPI 为 3×2，对应图边界和日期基线对齐。网络保留所有既有指标，不能按示例截图只留六张图。

布局按可用宽度和实际头部／图例／坐标开销分配绘图区；摘要折叠后图真实增高，不设固定 520 高上限裁切内容。窄屏允许重排与纵向滚动，不允许横向滚动、文字遮挡或缩到不可读。紧凑图卡为 400×190 验收，主窗口至少检查 960×680，放大图单独检查标签。

首页公司／制式下拉框保留箭头与文本内边距，长名称在实际文本预算内省略；统计公司标签按宿主宽度收缩，32 像素移除目标与 36 像素选择器内边距配套，不裁掉关闭图标。悬停补全只针对已省略的名称，完整显示的文字不机械重复提示。

视觉检查来自实际运行控件和模型，不能以生成示意图或只检查外框代替；记录窗口、DPI、模式、来源与提交。完整检查见[验收清单](../testing/acceptance.md)。
