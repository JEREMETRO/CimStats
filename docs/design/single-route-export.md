# 单线线路图导出设计

## 范围与入口

复用当前单线地图的真实查询快照、方向划分、指标倍率、公司显示名和站点可见性。从地图单线模式的现有导出按钮进入专用对话框；其他页面、线网与规划的既有导出不改写。无选中线路或数据未就绪时不能导出空白结果。不得读取 jobs 中的样例作为产品数据。

导出与主地图共用运营区段的站点符号定位规则，制图位置同时用于成品范围计算和站点绘制，原始停车坐标及统计数据保留。相同路径的上下行允许自然重叠，不添加人工侧移；成品沿用打印专用线宽与累计虚线节奏。预览、PNG、JPG 和 PDF 使用同一场景。

## 设置框

保持应用现有浅色 Fluent 控件、字体、边框、圆角、间距和动效。左侧预览，右侧设置；“导出设置／导出数据”两页，底部取消、导出。小窗口优先缩小预览，设置内容可滚动，操作栏固定，保留底部间距；窗口尺寸遵循 availableGeometry 提供的可用工作区。禁止新增悬停提示、开发说明、算法提示和占位入口。

两个页签支持反复双向点击，选中项与当前内容页始终一致；纯文字页签不预留图标空间，选中横条居中文字下方。

导出设置提供：

- 格式：PNG、JPG、PDF，默认 PNG。
- 绘制方向：上行、下行、全线；继承当前单线方向。真正环行与单行保持完整路径，不伪造上下行。
- 标出站点、绘制车库名称；车库名称只使用真实名称和位置。继承单线是否包含空放的选项，并允许在导出中调整；无真实空放路径不补连接。
- 画幅：16:9、16:10、3:2、A4，默认 3:2；所有画幅默认横向，均支持纵向。“画幅方向”入口始终可见，与上行／下行的绘制方向分开。
- 成品宽、高，单位毫米。非 A4 默认宽 254 mm，宽或高修改后锁定比例联动；纵向使用对应画幅的倒数比例，切换横纵保留当前宽度并联动高度。A4 固定 297×210 或 210×297 mm。
- 精度：80、150、300、600 ppi，默认 300；实时显示像素尺寸。像素为 round(mm / 25.4 × ppi)，横向 A4 300 ppi 为 3508×2480。
- 成品风格：日间、夜间。
- 公司 Logo：存档标志、自选图片、不显示；公司品牌配色：存档两色，允许用户自定义。缺资源时不伪造标志，保留公司名称；只在相关选择处给出简短必要状态。

“导出数据”只分为“线路信息”“客流数据”，复用现有字段名称、顺序与单位，提供独立勾选及全选／全不选。预览同步更新，不能用旧状态画面冒充最新预览。

## 数据与口径

固定抬头包含公司显示名、制式及线路名、方向、模拟日期。通过稳定线路对象身份关联，不按名字猜测公司或线路。

默认选择：运营时间、地图长度、核定时间、核定速度、站点数、当日发班、平均间隔、今日客流。运营时间位于线路信息首行；用户可以取消该项或全不选。

运营时间使用保存的原生星期掩码及每份完整时刻表的实际首末发班。工作日和周末时段不同时显示如“工作日06:00-22:00，周末08:00-21:00”；七天相同则只显示“06:00-22:00”。分段运营逐段列出，以“、”分隔，不跨停运空档合并。其他星期组合只合并时段完全相同的日期；跨午夜时刻注明“次日”。未知或不完整的时刻表显示“—”，确认无服务显示“停运”，不以车辆到站时间延长末班。运营时间保留可读宽度，纵向跨线路信息两栏；只在完整时段或星期组之间换行，不拆开时钟数字。

可选线路信息：线路车库、开线日期、最近改线日期、最大车辆需求、平均车辆需求、每周收入、每周支出。可选客流数据：平均客流、今日平均单班人次、今日平均车公里人次。完整字段来自 map_line_presentation.line_information 与现有单线指标，不另造数据口径。

地图长度沿用现有倍率及 selected_route_metrics 的方向与空放口径。方向站数、时间、速度由地图信息和导出共用指标入口提供。站数保留保存站序中的重复停站，方向分界站分别计入两侧；环行、单行和全线沿用完整线路的原始站数及可用性规则。不能把全线客流、发班、财务按方向平均拆分，必要的“全线”口径写入指标标签。0 与缺失分开，缺失用既有缺失显示；不借用其他周期。隐藏站点不影响站数与里程。导出设置不能改变软件当前筛选、视角或方向。

## 成品排版与字体

抬头采用“公司名称·城市公交”等真实对应制式名称一行；“503E 上行”为线路名与小号方向同一行。日期放右下角灰色小字“最后更新日期：…”，使用存档模拟日期，不使用电脑时间或线路最近改线日期。线路信息省去重复方向括号脚注；站点数使用所选方向的实际“上行站点数／下行站点数”，全线、环行和单行使用真实对应范围。财务、客流、发班的数据作用域保持原值。客流区域按所选指标显示“今日客流／平均客流”等标题，大号数字右侧以小字显示“人次”，标题和单位各显示一次。

整张独立成品，地图不限定正方形，先测量信息区所需空间，再使用剩余矩形区域；横向为左侧地图、右侧公司抬头、线路编号和两类数据，纵向为上方地图、下方信息区。地图投影保持横纵相同缩放比例，完整显示所选运营线路；两端外侧保留周边真实道路和建筑，横纵轴各侧边距至少占对应地图绘图区的 6%，且不少于 24 个设计坐标单位，方向图例另留空间。画幅变化只调整地图尺寸、间距与信息排版，绝不拉伸地图或裁掉运营路径。A4 纵向使用上图下信息，下方按可用宽度组织公司抬头及两类数据；字段全选必须布局预检，不重叠或静默丢字段。长名称可换行，不裁断线路标识。空的数据分类不留空标题。

全线成品不显示“全线”字样；往返线路以下行实线、上行虚线区分，地图内用真实线型示意及“上行／下行”标签组成图例，不写“实线／虚线”文字，图例与实际绘制一致且预留空间不遮挡线路或站点；虚线沿连续路径累计，不在每个几何段重新起算。仅一个方向使用实线，环行和单行保持完整实线；真实空放另用弱化线型，不与运营方向混淆。

在宽 1536 的设计坐标中，横向默认地图约占 1024，随信息预算调整；所有字号和线宽按成品坐标统一缩放。大号英文和数字必须指定 Segoe UI Variable，线路编号起始字号 112、字重 650，核心客流字号 76、字重 600；按真实测量缩放适配，不能依赖默认粗体。中文沿用共享 Microsoft YaHei UI。配置通过共享字体入口扩展，不能写第二套全局主题。

日间采用已确认的极简信息布局，清爽近白背景、低饱和多色建筑和清晰道路等级。避免单色蓝底图、脏暖灰；道路与建筑应弱于线路。夜间保留深蓝底、明亮线路、克制道路与建筑层次。真实底图类别色相从共享语义颜色派生，不能按像素随机染色。地图使用真实几何，不平滑改写路径，不增加无依据的水域绿地。

公司名称右侧同一行绘制 Logo，保留间距和安全边界；公司名称按实际宽度缩小字号，达到最小字号仍放不下时提示布局空间不足，Logo 保持比例。128×128 原图的可见标志约在设计稿 56–64 像素范围。

## 品牌数据及夜间提亮

公司对象 m_logo 是资源键，m_color1、m_color2 为两项 ARGB 整数；Logo 由游戏 company-logo 菜单映射到纹理，原纹理是掩码，必须按原 Shader 着色和计算透明度，不能直接绘制彩色掩码。八连交通集团是既有名称映射，真实键 arrow、CompanyLogo14、128×128，两色红 #FF0000 和白 #FFFFFF。不可把此样本硬编码成所有公司。

品牌色与软件 Fluent 强调色、公司统计身份色、运输制式色分别保存。品牌色只作用于导出抬头及克制强调，不重写应用和地图语义映射。

夜间深色内容按对比度提亮。保存原色不变，另生成显示颜色：文字针对实际背景达到至少 4.5:1，非文字关键标识至少 3:1；提亮时保持色相并验证对比度。八连夜间强调红以 #FF626B 为初始目标，随后校验背景。Logo 使用夜间派生两色通过同一掩码着色，保持形状与透明度。用户自定义深色也执行同一规则。预览、PNG、JPG、PDF 使用同一解析器。

## 渲染与执行

不可变导出请求冻结线路、存档身份、地图快照、选项、字段和品牌。GUI 线程只捕获必要快照及提交任务；布局、几何准备、高精度绘制与写文件在后台执行，不抓取 QWidget 整屏。取消、关闭和换存档淘汰过期结果，任务不得访问已销毁控件。

预览与最终文件共用布局和绘制逻辑。PNG 保留分辨率元数据，JPG 合成背景，PDF 保持路径及文字为矢量，ppi 只控制必须栅格化的部分。高精度按尺寸估算内存并采取有界分块／缓冲，不允许超大 QImage 导致进程崩溃；失败不留下貌似成功的文件。禁止保存地图磁盘缓存，不重新全量解析存档。真实 Logo 资源通过现有资产能力解析，不将 jobs 或本机绝对安装路径绑定进产品，不擅自分发未经核定的游戏资源。

## 验收

- 三格式、四画幅各两方向、四精度；像素与毫米一致，地图按剩余矩形适配且运营范围完整。
- 上／下／全线、单行、环行，真实空放与无空放；共享站、方向专属站与站点开关正确。
- 所有字段、空字段、缺失、零值、长公司／线路名、多公司同名及倍率，与单线信息一致。
- 真实 Logo 与透明掩码、缺资源、自选 Logo；日夜红色及其他深色的对比度。
- 1440×960、960×680 及 Windows 实际可用区、DPR 1/2；底部留白、滚动、关闭和取消可达。
- 实际 PNG/JPG/PDF 打开检查，PDF 路径与文字保持矢量，截图来自实际程序。
- 快速切换选项、换存档、取消、600 ppi，记录 GUI 响应与峰值内存。受影响测试后执行完整回归，构建包按发布清单验收。
