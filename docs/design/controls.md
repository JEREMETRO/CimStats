# 控件契约

本文件归并仍在使用的控件与交互规范；所有尺寸为 Qt 逻辑像素。0.1.0 问题修复形成持续设计基线，后续新增控件、图表和页面必须遵守相同约束。视觉常量见[视觉设计](visual-design.md)，图表规则见[图表需求](../requirements/charts.md)。

| 控件 | 约定 |
| --- | --- |
| 导航与子选项卡 | 保留实际入口，统计子选项卡使用 Fluent Pivot；窄窗允许换行，不能盖住文件信息、导出或打开按钮 |
| 公司多选 | Fluent 菜单和可移除选中标签，按稳定身份管理；标签随实际宽度省略，移除图标完整显示并保留键盘焦点；长名保留完整悬停与辅助名称，具体提示内容按逐项确认的口径实施 |
| 范围／粒度／维度 | 使用下拉选择；标准高 36、圆角 6、正文 14；主筛选在各模式保持相同位置 |
| 日期 | 快捷完整周／日；自定义弹窗分列起止并提供应用／取消，非法窗口禁用应用，取消不查询 |
| 分析模式 | 默认、多公司、同期三项常显互斥；多公司存档保持选择语义，单公司存档禁用多公司对比并清理失效设置；不同时提供重复模式入口 |
| 图形能力 | 图卡内紧凑互斥分段，只显示确实支持的类型；单项可隐藏无意义的切换 |
| 摘要切换 | 车库／站点、平均／最大、客流／出行量在对应摘要区域，不增重复工具栏 |
| 图标按钮 | Fluent 图标，轻边或无边，点击目标至少 32；完整 tooltip、accessibleName、键盘焦点 |
| 开关与菜单 | 二元值用真实开关，选项集合用菜单；主次按钮、日历、错误弹窗和悬停使用共享样式 |
| KPI | 标签、数值和单位分开；最新信息中型数值采用共享 600 字重，最大核心数值采用 700，标签与单位保持 400；长值、缺失、加载状态不改变卡高或挤掉单位 |

提醒“全部／更多”、公司“选择”和时间范围入口必须保留完整动作文字及箭头。使用共享 `button_text_size` 按控件完成样式初始化后的字形、实际内边距和箭头预留计算尺寸；不能只比较文字宽度与按钮外框，也不能缩小字号或省略动作文字。日期弹窗沿用同一字体和现有控件，不改范围含义。

首页窄窗第一行左侧为城市名，右侧日期与时钟并排；第二行左侧为人口，右侧为存档名。右侧信息靠右，城市名／时钟、人口／存档名共用文字基线；日期与时钟保留不同字号，按可见字形的视觉中心对齐，不能用相同字体框或基线代替视觉对齐。宽窗保留分列，提醒卡与上方信息区共用顶边和底边，窄窗共用左右边线。提醒高度根据实际内容与相邻区域分配，不能用固定高度裁掉提醒行或使外框居中错位；布局更新不改变快照和查询。

## 提示信息口径

提示用于补充当前入口未完整展示的信息。完整可见的名称、数值、单位或说明不在悬停中机械重复；文字确实省略时可补全文，需要消歧时只补尚未显示的身份。操作图标仍需简短动作提示，不能将辅助名称一并删除。

每个提示入口分别确定触发区域、必要信息、显示顺序、数值精度与单位、日期范围和缺失状态。逐项展示具体示例并确认后实施，不能将一组入口的同意推广到其他入口。公司称谓和身份规则保持一致，城市与统计图共用相同提示口径，避免同一值同时显示两套标签。小图去除常驻数字后，实际数值的可访问入口仍需保留并逐项核对。

共享时间柱提示只取当前指向的整柱，堆积分类不跨柱混入。本期和对比柱分别显示自己的真实日期与有效值；空白不命中，零值和负值保留命中。提示换行后按内容实际高度布局，超出小画布时由其拥有的浮层完整显示；浮层不接管鼠标或触控输入，随画布隐藏、取消和快照替换清理。原生与 Fluent 提示验收必须覆盖持续可见的短→长→短复用，不能只测隐藏再显示。

城市卡片不把完整可见的同一值用另一单位再列一次；保留实际观测时间、缺失原因及不完整状态。数值区域确实裁切时补全；以万人显示而精度截断了实际人数时保留精确人数入口，等值完整换算不重复。已取消的首页排行／制式整行提示不恢复；隐藏数字保留辅助名称读取，实际环形扇区继续提供数量、单位和占比。

## 共享接口

[FluentSegmentedControl](../../frontend/stats_controls.py)提供 `addItem(key, text, icon)`、`setCurrentKey(key)`、`currentKey()`、`setItemEnabled(key, enabled)`和 `currentKeyChanged`。首次添加默认首项；同项重复设置不重复发信号；禁用项不能由用户激活。程序化设置遵循信号语义，调用方需要静默更新时显式阻断信号，不另造一套分段控件。

[ChartPanel](../../frontend/stats_charts.py)通过 `set_mode_options(modes)`限制能力，`set_mode`不能激活不允许模式。合法当前类型保留，失效时选择首个允许类型；空集或无效键明确拒绝。时间柱 `trend-bar`与分类条形 `bar`不可混淆。公司现金流只使用时间柱，其余趋势不提供重复折线／面积按钮。

公司页使用固定四个指标图卡，不提供额外指标选择器、指标菜单或图位交换；不能把已不存在的菜单接口写成共享组件契约。满意度维度放在对应 KPI 内，多公司保持同步。页面通过公开接口使用图卡，不能通过私有布局成员注入另一套控件。

放大副本保持能力集、当前类型、公司／周期名称及分类显隐。公司和同期身份图例统一使用 `SeriesLegend`，参见[图表需求](../requirements/charts.md)。

[SchedulePanel](../../frontend/line_schedule_view.py)按线路模型的“显示日组”构建星期选择，隐藏运行日掩码低七位均为零的未启用记录，保留启用时刻表的零班次与午夜时刻。没有可展示内容时只保留标题和“暂无已启用时刻表”，隐藏星期选择、摘要、图例和展开入口；运行日未知仍显示诊断。`set_line`与`clear`必须清理旧内容、失效选择、悬停提示和滚动位置，切换回启用线路后恢复对应控件。过滤后的摘要由可见班次生成，不复用包含未启用记录的缓存；原始模型与导出数值不随显隐改变。

时刻表摘要先使用原有十轨对齐；宽度不足时，若七项完整标题与数值均可容纳，改用七等列保持单行；更窄时才换行。按实际字体测量，不缩小文字或班次单元格。线路页在 1436×900 客户区内应兼容侧栏展开和收起，常态完整显示 140 个班次，展开后显示 200 个班次；窄窗保留滚动。32 像素自绘标题栏计入客户区高度，线路页按标题栏、共享页头及页面边距后的真实剩余高度分配。时刻表上下内边距统一为 8 像素，保留水平内边距、标题与摘要字号、九张 86 像素事实卡及 348 像素详情区；矩阵字体保持 14 像素，常态行距至少 22 像素，展开后至少 28 像素，容量及末格可见性不以旧页面高度常量代替。页面使用共享页头、导出菜单及打开存档入口，不占用底部状态区域。

所有放大副本复用 `ChartPanel` 的详情标题栏动作：普通图为放大图标，详情为常显带图标和文字的“缩小”按钮，32 高、支持 Tab 焦点及键盘激活，并有完整辅助名称。`InlineChartDetail` 是主窗口中央内容区的白色子表面，不是顶层窗口；共享几何过渡从来源图卡展开、缩回，消费 `stats_motion.animations_enabled`，不复制系统动效策略。展开期间只保留一个详情表面，Tab／Shift+Tab 焦点留在详情内。缩小与 Escape 共用分类显隐回传，恢复来源焦点；全部隐藏、空数据或摘要类型时仍可缩小。来源隐藏、销毁、快照替换会取消详情和动画，取消不回传旧选择。公司、网络、城市和首页共用此展开路径，副本构建器不隐藏缩小动作。

## 触控输入契约

[touch_input.py](../../frontend/touch_input.py)由共享主题初始化安装一次，并在 QWidget 的 Polish 阶段接入新控件，因此新欢迎布局、菜单和弹窗不需要逐项接线。共享滚动区与图表单独使用时也安装同一策略，不再注册竞争的视口触控 QScroller 手势。

策略只接管触屏设备的触控事件。接受 TouchBegin 后，普通按钮、卡片和图表在抬手时才收到一次兼容鼠标按下／释放，防止 Qt 自动鼠标合成与自定义动作双触发。超过系统拖动阈值后，最近 QAbstractScrollArea 接收拖动位移；按行／列滚动的视图将像素换算为对应尺寸。ChartCanvas 复用鼠标检查的数据路径并为已缩放放大图提供横向平移。上下文长按发送现有 QContextMenuEvent，不创建菜单或改变信息口径。

文本编辑器立即接收兼容按下／拖动／释放以保留光标和文本选择，长按仍复用其编辑上下文动作。菜单、滑块、滚动条与原生选择器沿用 Qt 输入；需要自有触控的控件可设置 `nativeTouchInput` 属性。取消、多指、隐藏、失焦、销毁停止长按计时，取消点击、清理图表检查与拖动，并释放编辑器按下状态。鼠标、键盘与精密触摸板滚轮不经过此策略。

## 状态、动效与响应式

- 界面信息遵循最小展示基线：禁止擅自新增“卡片基准”、计算口径备注、内部实现信息或操作教学；不得把开发和指标文档搬进卡片或提示。新增说明及名称变化必须先按具体入口与用户商量，不能以“解释清楚”为由自行添加。车辆卡片标题固定为“车辆”，切换“平均／最大”和窗口重排都不改名，不显示最大需求口径备注。正常可见信息不机械重复，必要省略补全和真实缺失状态按已确认口径保留。
- 覆盖默认、悬停、按下、键盘焦点、禁用、展开、加载、空数据、错误，菜单和弹窗不能退回不一致的默认 Qt 外观。
- `initialize_theme` 在原生提示显示时应用独立的共享提示样式，防止来源控件的局部透明背景覆盖提示底色；图表内提示继续由共享画布绘制。
- 子选项卡和线路亮点悬停不增加描边；子选项卡点击得到的鼠标焦点也不绘制键盘焦点环。Tab／反向 Tab 等键盘焦点继续可见，亮点卡片保留静止边框及焦点可见性。
- 同期选择器占用稳定筛选位置；宽屏与窄屏重排不挤掉打开、导出和返回入口。
- 共享页头文件区在窄窗可收缩省略；首页公司与制式选择由父布局分配尺寸，选中长名不能主动撑大或盖住相邻控件。完整选项身份与键盘操作保留。
- 导出菜单每次更新仅包含当前动作与必要分隔行；没有首尾或连续分隔，反复更新不累积空行、动作对象或菜单高度。
- 悬停浮层采用独立字体，不继承标题、KPI或数据标签的强调样式：12个逻辑像素、常规字重400、当前浅色主题中性近黑文字；原生提示、Fluent班次／表格提示和图表自绘提示共用字体与颜色令牌。普通提示内容最大宽度320，长文换行；圆角4、细边框，不改变页面常驻文字。依据[WinUI ToolTip默认资源](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/CommonStyles/ToolTip_themeresources.xaml)；当前Qt实现使用不透明浅色背景，不声称提供原生WinUI Acrylic材质。
- 分类图例、公司／周期身份图例、顶栏存档文字、公司摘要名称、已选公司标签：完整显示时不重复提示，仅省略时补全文。重名公司缺少标识时提示“公司标识：真实完整ID”；名称也省略时先写完整名称，下一行写标识。名称和标识均完整可见时无提示，唯一名称不额外加标识。保留辅助名称；验收覆盖宽度恢复、重名和真实ID，不用固定编号替代身份。
- 折叠筛选采用单行分层摘要：公司、图表模式、统计时间、聚合粒度，字段之间以四个连续空格分隔，不使用间隔号；图表模式沿用当前选项原名，同期对比追加实际对比时间。城市页只保留适用条件。整日范围展示包含的实际日期，自定义时分范围明确结束不含；长公司名优先省略并悬停补全，完整内容不重复提示。
- 卡片自动比较的基准名称与日期放在卡片组现有标题行；同期模式已在筛选摘要显示对比时间时不再重复。存档身份与模拟时钟保持在全局顶栏。
- 线路公司／制式选择器与表格文本完整显示时不重复提示；截断时补全原文，保留原始数据及辅助信息。
- 线路列表底部选择摘要、详情标题及普通文字字段、事实卡主数值同样仅在截断时补全文；数字与小字号单位按实际绘制宽度判断，换行车库名按实际可见高度判断。异常原因、发班说明及计算口径等专用提示不被普通文字补全覆盖。
- 线路平均间隔的正常悬停说明使用“该线路该天运营时间内的平均间隔”，平均车辆需求数使用“游戏系统计算的线路平均车辆需求数”，不可计算时保留具体原因；平均客流使用“自开线以来的日均客流”。文案调整不改变统计算法或时刻表星期切换行为。
- 上述平均指标说明只挂在各自的次级名称和数值处，不挂整张事实卡，避免覆盖今日客流、理论最大车辆需求数等主指标的含义。
- 当日发班数的标题、数值和对应卡片不提供悬停说明，不能继承平均间隔说明。单个班次保持原有序号、完整时刻及车型提示。
- 时刻表摘要以“运营时间”替代分开的首班、末班，直接显示各运营段，用连字符连接起止时间、四个空格分隔各段；跨日标记保留，空间不足时换行而不截断。仅全天运营（00:00-24:00）提示“24小时运营线路”，多段运营提示“分时段运营线路”；普通连续运营不附说明。
- 各时段平均间隔的提示统一为“时段名称（实际时间范围）平均间隔”，范围来自当前计算使用的时段配置，多段完整列出，不硬编码时间；未知范围显示“时段未确认”。首页城市名称、日期、时钟完全取消悬停，包括截断和未识别状态，保留可见文字、辅助名称及底层来源数据。
- 摘要折叠控制使用固定按钮宿主，箭头随状态旋转；折叠后确实释放内容高度，不用低固定上限模拟折叠。
- 动效使用共享策略，遵循 Windows 关闭动画设置；不能通过反复重建控件、动画触发查询或布局回环制造卡顿。
- 图卡（含放大副本）及首页分类卡的显示使用 `attach_surface_reveal`，复用同一 `SurfaceMotion`。页面／子页进入采用短距离上移淡入（220ms），图形类型变化采用淡入（160ms）；数值、坐标、查询状态和画布实例不随动画帧变化，不逐帧缩放数据值。
- 同一窗口的父子表面只保留一层透明动效：父表面接管时结束子表面动效；已有祖先效果时由祖先呈现。外部效果不被替换；同窗详情先结束来源表面的动效，再播放展开／缩小的几何过渡，避免嵌套透明效果。隐藏立即结束动效并释放临时效果，快速重复操作从当前状态继续；静态 PNG 按完整快照绘制并恢复效果状态。
- `CollapseMotion` 收起／展开分别使用 167／250ms。已隐藏内容从零高度展开，反转从当前高度开始；过程中固定内容网格的自然行位置，由宿主裁切，避免卡片相互挤压。完成或父表面隐藏时恢复布局与高度约束，折叠确实释放空间。
- 动画关闭时立即应用完整终态，不修改 Windows 设置，不延迟输入或数据就绪。测试须分别验证系统策略与显式启用动画的条件，并检查实际中间帧，不能把本机关闭动画误判为实现缺失。
- 启动 Logo 遮罩与欢迎层覆盖同一个主窗口中央内容区并随 resize 重排。先绘制遮罩再加载业务模块，欢迎层完整首帧就绪后以约 333ms 的上移和内容淡入显示打开入口，使用 `stats_motion.animations_enabled()`，关闭动画直接到达终态。启动期间原生窗口身份保持不变；不创建另一个启动窗口。过渡不中断打开或拖放，不用定时等待延迟应用就绪；被覆盖的导航及页面控件不进入键盘焦点链，窗口系统按钮和打开入口保持可达，成功切页后恢复。

- 主窗口标题栏与页面共用 `PAGE_BG` 画布，不绘制独立色带、分隔线或阴影，二级窗口标题栏沿用本窗口表面颜色；About 只保留文字身份、版本与声明入口，不显示品牌符号。欢迎到导入进度、进度到就绪页面以约 220ms 的旧表面快照退场衔接；实时界面立即就绪，过渡快照不接受输入。不嵌套透明度效果，重复导入、窗口隐藏或 resize 立即清理快照；系统关闭动画时不创建过渡。
