# 历史缓冲区与统计口径

本文件归并统计中心与网络聚合的有效口径。摘要索引见[指标口径](../DATA_DEFINITIONS.md)，线路即时周化值另见[线路指标](line-metrics.md)。

## HistoryData

- `AddData`把值和分母累积到当前观测；`TimeStep`写入 768 槽环形历史并按字段性质重置增量。增量槽已是该时段的量，**不能再取相邻槽位差**；存量槽也不能跨小时求和。
- `m_position`对应当前模拟小时，并非天然无效槽；当前小时可能只有部分观测，需区分值可用与周期完整。
- 时间戳按模拟小时和环形位置还原，创建前、保存历史外及未写入的槽不能补零。具体索引计算见 [history_contract.py](../../src/history_contract.py)。
- 身份用实际 `CompanyData`对象引用与 `PlayerData`归属映射，优先稳定玩家／公司 ID，缺 ID 时使用索引。名称只作显示，不合并重名公司；同公司多人仍是一个公司对象。
- 查询区间为 `[start, end)`；纯日期末日换算到次日零点。默认上一完整周按模拟周一计算，不是滚动最近七天。

## 指标契约

| 指标 | 换算与聚合 |
| --- | --- |
| 现金流 | 原始货币子单位除以 100，时段增量合计；不是账户余额或线路周化估计 |
| 公司价值 | 期末同刻资产分项合计，已是货币单位，不再次除以 100，不跨小时累加 |
| 月票使用率／受欢迎程度 | 按有效配对分子、分母汇总，不能简单平均小时百分比 |
| 速度／费用／质量满意度 | 分子、分母配对加权，保留负值和真实评分，不统一钳制为 0–100 |
| 声誉 | 有效期末比值，不当作时段增量 |
| 线路／站点／车库 | 期末有效存量，总体对齐同一时刻；站点总数不宣称空间去重 |
| 平均运行车辆 | 小时固定点平均除以 1024；不是资产车辆、时刻表最大配车或瞬时最大运行车辆 |
| 覆盖率 | 有效分子／分母配对统计，无空间去重证据时不显示多公司总体覆盖率 |
| 客流分制式／分群体 | 同一客流的两种分解，分别汇总，不重复相加 |
| 票制／覆盖区数行程 | 保留原分类语义，不重新命名为 OD 或发班次数 |
| 换乘系数 | 同范围有效配对客流总量／出行总量，不平均各小时系数，不钳制为 0–1 |
| 人口 | 期末有效分群体存量，同刻可相加，不跨小时累计 |
| 城市出行量 | 时段数量累计，桶值也是累计，不冒称每日平均 |
| 平均出行时间 | 真实时间总量／有效分母加权；没有分母不可算，不能以人口代替 |
| 交通方式 | 同一总体的有效计数配对构成；只有可比同总体才画饼，不强制三项归一化 |
| 交通密度 | 道路与轨道分别取最细有效小时观测峰值，不用周期均值的峰值代替 |
| 经济增长／利率 | 分开的核实字段和时点，不解释为 GDP、现实金额或年化 |
| 能源价格 | 城市模型按核实比例除以 100，单位为游戏显示值；不编造人民币／升。通用统计模型的原始项仍有未确认标记，不套用另一模型的转换 |

## 有效性与总体

缺失不是零。某分类可用不表示所有分类、整个小时或完整周期可用。比例分子、分母必须同公司、同分类、同时间配对；全部缺失不输出零。

已观测的零分母桶本身不生成有效比值，但其真实分子仍参与更长窗口汇总，不能因桶值不可计算就丢掉分子。例如 `10/0 + 20/10`的百分比汇总是 `(10 + 20) / (0 + 10) × 100 = 300%`，不是过滤首桶后的 200%。未观测、缺配对或身份／时间不一致的输入不能按此例当零处理；保留不完整标记，换乘系数还需验证两类计数时间集合一致。整个窗口分母合计仍为零时结果不可计算。

公司总体存量取共同有效时点，不拼各公司的不同日期末值；流量按有效配对数量相加，缺分类和缺公司不补零。分类显隐只是呈现行为，不能改变总体、分母或导出。公司身份或数据范围不匹配时不能生成比较结果。

## 网络最后日摘要

[network_model._last_day_result](../../src/network_model.py)从窗口结束边界确定最后一个自然日，再与所选窗口相交。平均车辆先对齐有效小时分类，再算小时均值；覆盖率汇总配对分子、分母后取比例；换乘系数先汇总配对客流和出行量，再相除。不是整个窗口平均，也不是各小时比例的简单平均。

最后日不足全天、当前小时部分或观测缺失时保留不完整标记，不回退到更早完整日。趋势仍按所选粒度聚合，不把摘要值复制成各桶值。小时均值不能推导可靠瞬时峰值；车辆摘要“最大”改用所选公司当前线路的最大车辆需求合计，明确标注存档当前并不生成历史涨跌，历史图仍采用平均运行车辆。当前需求的缺失与零规则见[指标口径](../DATA_DEFINITIONS.md)。

## 比较与验证

默认、多公司、同期互斥；同期比较各公司自己的两个周期，非同期提交空比较窗口。不等长周期按相对时间对齐并显示真实时间，不截掉较长周期尾部，也不计算不可比增长。

百分点与相对百分比区分，缺基准不能显示涨跌或触发提醒；颜色不是通用经营评价。测试入口：[test_history_contract.py](../../src/test_history_contract.py)、[test_statistics_model.py](../../src/test_statistics_model.py)、[test_network_model.py](../../src/test_network_model.py)、[test_city_model.py](../../src/test_city_model.py)。
