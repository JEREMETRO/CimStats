# 可读取字段与使用边界

本表说明解析对象和可计算能力，不表示每个字段已经有对应界面。字段实际可用性随存档、地图、规则集和解析结果变化，不以样例数量作为验收阈值。

| 数据组 | 可读取内容 | 使用边界 |
| --- | --- | --- |
| 城市与身份 | 模拟时钟、地图／城市名称、玩家和公司映射 | 电脑时间不参与模拟统计；重名按稳定身份消歧 |
| 公司财务 | 收入、支出、分制式成本、价格和工资 | 即时平滑周化值与历史现金流分开 |
| 车辆与制式 | 车型、容量、能源、维护、资产与运行信息 | 小时运行平均、资产数、时刻表配车不可互换 |
| 线路 | 名称、稳定 ID、站点序列、车库、路径、创建／改线、累计客流 | 缓存可能失效；不能恢复未序列化的首次启用时间 |
| 时刻表 | 活跃日期掩码、班次模板、首末班、发班记录 | 班次来自实际计划，不来自城市出行数量 |
| 站点与道路 | 类型、对象身份、道路长度、连接、覆盖参数 | 站点数不自动空间去重，覆盖半径不是线路长度 |
| 车型与道路资产 | 尺寸、速度、容量、车道及人行道／站台宽度 | 资产参数与游戏统计显示单位分开，见[几何与车型](geometry-and-vehicles.md) |
| 公司历史 | 现金流、价值、满意度、月票、声誉、受欢迎程度 | 值与分母、时点与增量、完整性均保留 |
| 网络历史 | 设施、运行车辆、覆盖、制式／群体客流、票制行程 | 同一客流的不同分解不能重复相加 |
| 城市历史 | 人口、出行数量／时间／方式、经济、能源、交通密度 | 使用各自核实尺度，不编造 GDP、现实货币或日均量 |

历史输出保留指标、对象／公司身份、分类、时间、原始值、分母、换算尺度和完整性。增量槽已是时段数量，不能再次取相邻差；详细聚合见[历史指标](history-metrics.md)。

## 可计算与不可推断

实际路径和计划可用于重算线路里程、预计行程、时刻表峰值配车、班次及核定速度。分群体／制式客流可作结构分析，费用和周化收支可作相同尺度的效率分析。是否展示由[产品需求](../requirements/product.md)与模型能力集决定，不凭“可计算”添加虚构图卡。

缺失的逐小时线路客流、未保存的首次启用日期、无空间去重依据的总体覆盖、无可靠分母的平均时间和无峰值观测的最大运行车辆不能补造。居民路径包含随机扰动，不是无随机误差的确定总客流函数，见[居民寻路与票价](passenger-routing.md)。

字段导出工具与审计入口见[工具索引](tools.md)，输入及结果需由实际任务重新验证。
