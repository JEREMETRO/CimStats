## 迁入资料

[旧仓库文档迁移索引](history/legacy/INDEX.md)记录全部迁入来源、重复内容的归并位置、历史不同版本和文件校验值。资料来自更名前主目录、保留的工作区及可恢复的 Git 文档，不搬回旧代码、发布包、运行过程文件或依赖缓存。

- `history/legacy/main/`：旧主目录及其存档中保存的文档，保持原有相对路径。
- `history/legacy/variants/`：旧工作区新增或与主目录不同的文档，按来源隔离。
- 完全相同的原文只保存一份；迁移清单记录每个来源到其保留位置的对应关系。
- 历史截图、存档和构建输出不随文档重新迁入。历史材料中的本机路径或证据链接仅作当时记录，不能据此声称本次已验证。

旧资料保留原文，不把日期、版本号和旧架构批量替换成当前版本。当前需求的整理结论见上方两份需求文档；查数据来源和决策背景时再阅读历史设计、审计、验收及交接原文。
