# 版本记录

## CimStats 0.1.0（2026-10-02）

新品牌首个公开版本，作者 JEREMETRO。旧 CIM2 SaveStats 1.0.0 及以下保留为本地历史记录。

- 公司、网络、城市三个统计子选项卡，统一 Fluent 界面与强调字体。
- 最新信息首页、线路与时刻表布局更新；首页默认浅蓝，保留正蓝调用模式。
- 恢复有效变化指标，区分缺失基准、真实零与持平。
- 新品牌图标、启动页及关于弹窗。
- 单文件 exe 发布，双击即用，无需安装 Python。
- 完善用户、开发、指标、贡献、安全及发布文档。

## 1.0.0 — 四看板 Fluent 界面正式版（2026-09-27）

本地历史版本（旧品牌 CIM2 SaveStats）。

- 浅色侧边汉堡菜单与四看板统计页；小窗口自动重排。
- 分群体、分制式、分区各自切换总量／条形图／折线图／饼图。
- 统一零基线和整数数值轴；缺失数据不补零。
- 统计提醒支持已读持久化；统计 PNG 和 XLSX 共用查询结果。
- 使用 QFluentWidgets 浅色控件、蓝白看板与稳定公司配色。
- 保留公司概览与线路查询功能及原有 XLSX 导出。
