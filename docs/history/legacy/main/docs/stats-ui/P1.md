# 统计数据页面与应用外框改版计划

## 1. 目标与范围

保留现有 PySide6／Qt 技术栈，采用**浅色 WinUI／Fluent 风格、侧边汉堡菜单、四块统计看板**。参考图片的信息组织与蓝白配色，不追求像素级复刻。

- 侧栏保留“公司概览、线路查询、统计数据”，支持展开与折叠；保留系统标题栏。
- 其他页面保留功能与内容，仅适配公共外框和控件风格。
- 单次载入一个存档，支持公司多选；公司数据分别对比，城市数据只显示一次。
- 移除统计页的聚合明细、原始小时追溯、全部原始字段入口；保留图表悬浮数值。
- 本次不迁移 WinUI 3，不增加图片中的地图、车辆管理等页面。

## 2. 布局与公共交互

- 顶部工具区提供：当前存档及打开操作、公司多选、小时／日／周／月粒度、时间范围、周期对比、提醒开关、导出。
- 默认选择全部公司，展示最近 **7 个完整模拟日**，按日统计，与之前 7 日比较。历史不足时展示实际可用数据并标注缺失，不补零、不生成无依据的变化提醒。
- 保留关闭对比、上一等长区间、上周同期、上月同期和自定义对比。
- 按内容区宽度重排：≥1400 使用两列四看板及右侧提醒栏；1000—1399 使用两列看板、提醒置后；更窄时单列纵向滚动。侧栏在小窗口默认折叠。
- 使用浅灰背景、白色卡片、蓝色强调、统一线性图标，减少重复边框。保存侧栏状态、指标选择和图表类型。
- 多家公司使用稳定颜色；分类构成按公司分别呈现。不同单位的多指标使用时间轴对齐的小图，避免混用同一数值轴。

## 3. 四块看板

### 公司与服务

- 公司看板：现金流、公司价值、月票使用率、满意度、声誉、受欢迎程度。满意度默认速度评分，可切换费用、质量；支持最多三个指标对比。
- 默认现金流用柱状趋势，其他公司指标用折线趋势。
- 服务看板：线路数、分制式站点数、车库数、平均运行车辆数、覆盖率，辅以线路趋势和站点分类。
- 站点不同制式不自动合计成去重站点总数；平均运行车辆数不改称车辆拥有量。

### 客流

设置**分群体、分制式、分区三个独立区域**，各自提供四种视图：

| 视图 | 展示规则 |
|---|---|
| 总统计数据 | 所选时段的总量大数字；多家公司分别显示 |
| 条形图 | 所选时段各类别累计数量 |
| 折线图 | 按所选时间粒度显示各类别趋势 |
| 饼图 | 所选时段各类别占比；多家公司分别绘制 |

- 默认：分群体折线图、分制式饼图、分区条形图；各区域独立记忆选择。
- 分群体与分制式均为乘车人次的分类，二者合计不能相加。
- 分区显示单线、一区、二区、三区、四区等游戏类别，标注为“分区出行量”，不使用城区名称。
- 分类显示开关只控制图表可见内容，不改变总量和系数计算口径。
- 恢复平均换乘系数卡片和趋势：

  **平均换乘系数＝同公司、同时间范围的总乘车人次 ÷ 分区出行量合计。**

- 分子固定使用分制式合计，分群体合计用于核验；周期汇总采用总分子除以总分母，不平均小时系数。
- 系数展示两位小数，并说明它是时段统计比值。零分母显示“不可计算”；缺失数据不补零，不裁剪异常比值，也不把系数下降自动解释为改善。

### 城市

- 展示人口、经济增长／利率、能源价格、出行量、出行方式占比及交通密度。
- GDP 替换为已有经济指标；能源价格明确标注游戏原始值。
- 出行量默认柱状趋势，其他趋势用折线；道路／轨道密度分开。
- 出行方式占比采用条形图，不强制归一为 100%。

## 4. 数据实现、提醒与导出

- 在现有统计查询模型之上增加四看板批量查询和展示结果层，复用已有金额换算、聚合和完整度规则。
- 扩展换乘系数查询，并同步修订原有“不可计算”的文档结论；区分公司统计系数与全市去重行程指标。
- 保留后台查询、取消过期请求机制，确保快速切换存档或筛选时不会显示旧结果。
- 提醒汇总四看板可比较指标，沿用现有阈值规则，支持单条／全部已读及重启保留。已读标识关联存档内容、公司、指标和比较窗口；数值变化生成新提醒。
- 提供 PNG 与 XLSX 两种导出：PNG 输出完整看板而非仅可见屏幕；XLSX 包含筛选说明及四看板的数值结果、单位、时间和完整度，不导出原始小时追溯表。
- 界面和两种导出复用同一份查询结果，保证口径一致。

## 5. 验证与交付

- 用已检查的单人、多人样本验证分群体／分制式合计一致，换乘系数分别可复算为约 **3.1513、2.6771、2.4776**；这些值对应已核查的历史范围，不作为默认七日窗口的固定结果。
- 验证三个客流区域四种视图切换后数量一致，饼图总量为零时显示空态，多公司数据不混合。
- 覆盖缺小时、零分母、未完成周期、无比较数据、重复公司名和快速切换查询。
- 检查侧栏折叠、窗口重排、常见显示缩放、提醒已读持久化，以及 PNG／XLSX 中文与数值一致性。
- 执行统计专项测试与全量回归，再检查真实存档界面和候选包。交付修改源码及候选程序；正式版替换另按项目发布流程办理。

本轮仅完成规划；实现时先完成外框和四看板，再接入视图切换、换乘系数、提醒与导出，最后统一验证。
