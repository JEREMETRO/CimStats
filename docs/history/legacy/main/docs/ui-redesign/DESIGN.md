# 统计数据页：已确认的视觉与交互规范

最新控件选择及返回前自查要求见[VISUAL-ACCEPTANCE.md](VISUAL-ACCEPTANCE.md)，冲突时以该文件为准：Pivot子选项卡、分段式分析模式/图形类型、实际截图对照验收。

日期：2026-09-29。技术栈保持 PySide6 + PySide6-Fluent-Widgets + QtCharts，不重写为 C#/WinUI。目标是参考图中的 Windows Fluent 桌面视觉与交互，不能只给旧页面换圆角和配色。

## 1. 参考依据与范围

必须打开 README.md 中三张原图。图三用于默认双公司布局，图一用于多公司同图对比，图二用于同期对比。截图中的双选项卡、公司摘要大头部、示例单位、运营评级和默认日期均已被后续要求覆盖，不照抄。

公司页为本轮重设计重点。顶部保留标题栏、文件信息、打开存档和更多操作；左侧保留现有可用功能入口，按 NavigationView 风格统一呈现，不凭截图增加不可用页面。统计页改为公司数据／网络数据／城市数据，默认激活公司数据。网络页承接原服务规模和客流看板，城市页承接原城市看板，不丢原指标。统一外壳样式不代表扩大到所有业务页重构。

## 2. 布局与三模式

固定区域顺序：窗口标题栏 → 页面标题与文件操作 → 三个子选项卡 → 全局筛选卡。仅下面的数据区纵向滚动；禁止整个页面连筛选栏一起滚动、双公司各有独立竖向滚动条。

| 模式（精确中文） | KPI布局 | 图表布局与语义 |
| --- | --- | --- |
| 默认模式 | 一家公司六卡；多家公司分别显示六卡 | 单公司2×2；两家公司等宽双栏，每栏2×2，各自仅绘制本公司当前数据，无周期叠加 |
| 多公司对比 | 公司KPI分组并列 | 下方公共2×2大图，每张图叠加所选公司的相同指标，横向比较公司；不叠加历史周期 |
| 同期对比 | 与默认模式一致 | 单公司2×2；两家公司左右双栏；每张图叠加本公司的当前周期和对比周期，纵向比较时间；不将其他公司混入该公司的图卡 |

公司数不决定分析模式：选择两家公司仍可处于默认模式。零家公司为空状态，不偷偷查询全部公司；多公司对比只选一家时显示简短的“请选择至少两家公司”提示，KPI保留，公共图可展示单条已有数据；不得自动切换模式或编造第二家公司。三家以上默认/同期模式按两列多行展示，窄窗口堆叠；同图对比使用有限一致配色和可换行图例。

删除整个公司摘要装饰头部（建筑图标、公司描述、运营评级、更新时间）。仅用紧凑公司名称及色点区分分组，不新增宣传语。长名省略并在悬停/辅助功能名称中保留全名，重名沿用公司ID消歧。

默认四个图位依次为现金流、公司价值、受欢迎程度、月票使用率。每个图位提供指标切换，六项指标均可查看（另外两项为满意度、声誉）；选择已在其他位置的指标时交换位置，不生成重复图。多公司各栏同位置、满意度维度和图表表现设置同步。现金流默认柱状，其余默认折线；非现金流支持折线／面积折线切换。满意度保留速度／费用／质量三个现有维度，新安装默认速度满意度，已有合法设置继续沿用。

KPI顺序固定为现金流、公司价值、月票使用率、满意度、声誉、受欢迎程度。单公司宽屏一行六卡；双公司每栏3×2。工具栏位于KPI与图表之间，无重复大标题；全屏操作保留。

## 3. 日期简化与统计口径

筛选卡常态显示公司多选、统计范围、时间粒度、分析模式；第二行放实际范围辅助文字、提醒阈值、关键变化提醒和导出。进入同期对比再显示对比周期选择，布局不能因此挤掉导出。

- 统计范围选项：上一完整周（默认）、上一完整日、自定义时间。全部相对存档模拟时间计算，与电脑日期无关。
- 上一完整周：先取模拟时间所在周的周一00:00，再向前7日；上一完整日：模拟日期前一天00:00到模拟日期当天00:00。
- 所有区间为[start, end)，包括起点、不包括终点；严禁重复计算相邻周期边界。
- 常态不展示开始/结束两个输入框，仅显示实际起止范围文字。选择自定义后弹出Fluent风格双日期选择面板，支持鼠标日历及可选时分，提供应用和取消；取消不触发查询。纯日期选择将末日按包含该日解释，内部换算到次日00:00；显示文本说明实际范围，含时分时显示真实排他结束时刻。
- 时间粒度保持小时／日／周／月独立选择。默认沿用已有合法粒度，未设置时使用日；不能为了图形密集而伪造小时数据。
- 分析模式默认默认模式。对比周期仅在同期对比显示，默认上一段等长时间，可选上周同期、上月同期、自定义。快捷周期复用已有 compare_window 的历法规则，月末按现有规则截到有效日期。
- 当前范围变动时，非自定义对比周期自动重算；自定义对比范围保持用户设置；非同期模式提交 comparison=None，避免旧比较状态污染图表和导出。
- 起止无效时禁止应用并显示字段内错误；历史不足时按真实值/缺失值展示，并提示“该范围数据不完整”，不得自动改成最近有数据时间或补零。
- 不等长自定义周期保留现有比较对齐与提醒约束：不截掉超出当前周期的对比数据，不对不具备可比条件的数据生成误导性的增长提醒；图中按相对周期位置对齐，tooltip显示各自真实日期。

时间例：模拟时间2024-03-01 13:00（周五），上一完整周应为2024-02-19 00:00至2024-02-26 00:00，不是滚动最近7天。模拟时间为周一00:00时，上一完整周仍为刚结束的7天。

## 4. Fluent 视觉规格

以下为批准的实现起点而非声称原图像素取样；比例和一致性优先。所有尺寸使用Qt逻辑像素，不能用设备截图物理像素生搬硬套。

| 项目 | 规范 |
| --- | --- |
| 外壳 | 浅蓝灰连续背景，保留标准最小化/最大化/关闭；不为模仿Mica引入不稳定原生窗体依赖 |
| 背景/表面 | 页面建议#F4F8FC，卡片白色；边框建议#E3EAF3，柔和低透明阴影；不叠加浓蓝渐变和厚重双层边框 |
| 强调色 | 控件主蓝#0067C0，图表蓝#1677FF，公司B青绿#00A67A；公司色表达身份，不表达好坏 |
| 文字 | 主要文字#18314F、辅助文字#65758B；微软雅黑UI，中文回退可靠；正文14、辅助12、图标题15–16、KPI数值20–22、页标题28–30 |
| 间距 | 页面20、板块16、内部12–16、关联控件8；所有卡片边缘与文字基线对齐 |
| 圆角 | 大卡约12，KPI/图卡约8，控件约6；阴影仅用于必要浮层与大表面，不给每个小控件叠阴影 |
| 导航 | 展开180–200，窄态约48；导航项44，线性图标，选中浅蓝底＋蓝色文字＋左侧短竖条；保留实际功能入口 |
| 顶部 | 约48图标底座＋统计数据标题＋简短说明；右侧文件图标/文件名/存档日期，打开存档主按钮和更多图标按钮；对齐于同一标题区 |
| 子选项卡 | 图标＋中文标签，当前项蓝色及底部细选中线；不用后台网站胶囊导航样式 |
| 控件 | 标准高36；下拉框、日期弹窗、公司多选标签、开关、主/次按钮统一边框、内距、图标与焦点；公司选中项可移除 |
| KPI | 小图标在左，右侧标签/数值/单位；数值醒目但不超粗；单位次级，不硬编码万元或百分比 |

本轮按用户指定浅色主题验收，沿用现有浅色约束，不另外扩展深色主题工程。

完整状态必须覆盖默认、hover、pressed、keyboard focus、disabled、展开、加载、空数据和错误。下拉菜单、日历、提醒阈值对话框、导出菜单、tooltip和全屏图表均需采用同一视觉规则，不允许主体Fluent而弹出控件仍为默认Qt外观。统一键盘Tab顺序、按钮辅助名称与可见焦点。

## 5. 图表专项规格

- 左上小图标与标题，右上紧凑图例及全屏操作；绘图区白底与图卡连续，去除默认QtCharts背景和厚边框。
- 水平轻网格为主，坐标轴线细；按可用宽度减少标签但保留完整tooltip，不旋转一排密集日期导致图高失衡。
- 折线约2逻辑像素，点密集时不逐点画圆点，hover突出当前点；面积填充透明度约8–12%，不过度渐变。
- 同图多公司用蓝/青绿及一致补充色；同期同公司当前为深色实线、对比为浅色虚线，图例不只靠颜色区别；柱状按时间桶成组，不用遮挡方式隐去一组。
- 统一同指标所有可见公司的量程、刻度、单位和时间窗口；同期量程覆盖当前与对比数据。现金流含负值时保留零基线；比例和满意度不混用量程。
- 对应图卡绘图区边界、图例高度和日期标签基线对齐。共用颜色表，每次会话按公司ID稳定排序分配，选择子集不改变该公司颜色。
- tooltip包含公司、指标、周期、真实日期、数值和单位；默认/同期双栏同指标hover联动相对时间位置，不能触发无限信号回环。
- 缺失值为断点，不补零、不用平滑插值篡改数据。图例切换、hover、全屏不得改变查询结果或XLSX数值。

## 6. 响应式与验收

1600×1000逻辑窗口为主要基准；1920×1200宽屏复核，1366×768/920×680为可用性复核。默认单公司六KPI及2×2图在主要基准一屏显示，不强求小屏无滚动。

内容宽度>=1120时双公司双栏、每栏2×2；720–1119时保留双栏但每栏图表一列以确保坐标可读；<720时公司分组竖排。单公司内容宽度>=720采用2×2，低于该值单列。导航收窄、筛选可重排；不能出现整页横向滚动或无法访问的操作。

实际截图覆盖三模式、单/双公司、跨期、自定义日期弹窗、长公司名、空数据、125%/150%DPI。为对照参考图，另提供固定演示数据的标记为演示的截图；功能验收必须再用现有真实存档，演示数据不得成为默认业务数据。

交付真实运行UI截图，不用生成图冒充已实现界面。每张图保留窗口尺寸、DPI、模式、数据来源与提交号；实现差异表逐条说明相对原图的有意修改与未完成项。
