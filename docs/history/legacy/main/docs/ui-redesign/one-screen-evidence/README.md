# 各模式、各分辨率截图

真实存档完整窗口截图。测试环境：Windows 缩放 100%，Qt 逻辑 DPI 96。每张图片显示整个应用窗口；文件名注明存档人数、页面、模式和窗口分辨率。

展开状态可点击“确定”收起筛选；收起状态显示已选公司、时间、粒度、模式等参数，并可点击“展开筛选”继续调整。

此目录中的截图已按共用卡片按钮样式、Fluent 覆盖式滚动条和紧凑同期图表合并后的版本重新采集。
