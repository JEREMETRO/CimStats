# 追加 UI 验收

用户最终选择恢复普通浅色 Mica（type2）。原生截图与脚本已更新为 type2；历史 type4 对比图保留在此前提交419eb38中。黑屏生命周期修复与数据卡片调整保留。

每组 Qt offscreen 独立进程通过 `QT_SCALE_FACTOR` 模拟系统缩放，逻辑窗口=目标物理尺寸/缩放比例；不是实际修改 Windows 显示设置。数据为此前真实单/多人存档解析生成的 session 缓存，避免干扰性能线程基准。原始真实解析验收在相邻 `refinement-evidence`。

5组目标：2880×1920/200%、1920×1080/100%、2560×1440/125%、3840×2160/175%、2560×1600/150%。各组 `measurements-*.json` 记录实际 DPR/geometry/viewport、卡片边界、图表重叠、滚动、原件及probe哈希；公司默认与网络总体在摘要展开/折叠/恢复均通过 H/V=0、内容在视口内、无图表重叠。同期剩余滚动按实际结果记录。

公司图展示满意度下拉直接位于满意度 KPI 标题行、图标标题居中、摘要卡与图表独立。

`native-mica-multi-company.png` 为 Windows 原生激活窗口截图，由 `qa_native_mica.py` 生成。此环境实际3840×2160/175%，DPR1.75，窗口1440×960逻辑，截图2520×1680；普通 Mica DWM type2，系统透明效果开启。使用临时置顶测试窗口防止误截其他应用，校验前台窗口身份后截图。它只证明此环境原生背景效果，不代表全屏最大化或其余四组原生系统缩放/实体鼠标命中已实测。单帧不证明连续无闪黑。Mica 失去激活时由系统回退纯色，非测试失败。
