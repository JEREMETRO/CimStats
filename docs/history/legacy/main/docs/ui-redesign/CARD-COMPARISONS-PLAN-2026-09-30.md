# 数据卡片比较摘要

用户要求先复述方案再实施，已在聊天中复述。统一在主值下显示比较摘要，保留既有主值与汇总口径。

1. 默认/总体（以用户后续澄清为准）：完整日/周/月与上一完整周期比较；自定义范围向前平移足够的整周，保持星期结构且不重叠，例如周末比上周末。比较整个所选窗口，保持与卡片主值同口径。上一窗口可以在当前筛选范围之外，缺失不跨周期寻找替代。
2. 同比：当前卡片值与自定义/已选择同比范围的同口径汇总值比较，提示双方实际区间。
3. 双公司：该项指标与另一家公司的同口径值比较；多公司：数值降序、并列采用竞赛排名，显示名次和距最高值的差距。缺失公司不伪造名次，提示数据不全。
4. 占比指标用点（比率差0.01对应1点）；其他指标用 `(当前-基准)/abs(基准)*100%`。基准零用绝对变化（同零显示持平），负基准可计算；缺测不补零。颜色仅标数值增减，不评价经营好坏。
5. 卡片下方摘要和悬停详情共用纯数据对象；公司、网络、城市接入，导出保留同一摘要口径。

按 test-driven-development 与 verification-before-completion 顺序执行：比较算术/并列/零负值/缺测检查 → 窗口与同口径聚合 → 卡片接入 → 布局和导出 → 相关回归与真实缓存效果截图。只修改本任务文件，不暂存已有 probe 修改，不推送。
