## 设计与文件责任

`src/city_model.py` 从 HistoryStore 的无公司归属原始记录构造 CitySnapshot；不依赖公司选择/同期。快照内五 KPI、六 Result、观测时间、完整性、构成有效性共用范围与粒度。`frontend/city_dashboard.py` 使用 ChartPanel/FluentChartView，管理饼/折线及曲线多选，仅重绘不重查。`frontend/statistics_page.py` 负责异步任务/token、城市筛选和页面接入。`frontend/stats_exports.py`/`stats_integration.py` 导出当前城市快照及显示偏好。共享图表只增加必要公开扩展，不改变公司/网络默认行为。

城市只有全市范围，无公司选择或模式，范围/小时日周月、阈值、提醒开关、相邻确定/导出沿用共享控件。宽屏五 KPI 同排、六图 3×2，按内容逻辑宽度退为2列/1列并允许滚动；不缩小字号强挤。所有六图始终存在：人口、出行量、方式、出行时间、经济/利率、能源。无密度趋势图。全屏保持当前图形、曲线、图例与范围。

2026-09-30 用户修正：图线显隐仅通过点击图例色块/条目控制，不提供图线选择下拉菜单。全部实际群体始终保留在图例中；隐藏项灰显，再次点击恢复。出行时间默认只显示平均线，允许全部隐藏；偏好持久化，主图与全屏即时同步，显隐不影响平均指标计算。

后续修正：城市筛选标签与控件同行，宽屏范围/粒度/设置/提醒/确定/导出合为一行，实际范围单列一行说明；窄屏按钮换行。交通密度卡片将无量纲分子/分母转为百分比，不再展示“原始比率”，道路与轨道分别保留最大小时记录及观测时间。
