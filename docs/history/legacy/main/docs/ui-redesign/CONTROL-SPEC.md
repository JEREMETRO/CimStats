# 原图控件效果提取与全局替换指令

2026-09-29用户要求逐控件提取、明确派发、统一替换并调节布局。依据实际打开的公司图01/02/03及网络图03/04/05。以下为实施规范，不伪称位图精确取样；业务规则和用户删除项继续优先。

## 1. 原图共同视觉骨架

原图不是灰色控件贴在白色窗口上：标题栏与导航形成连续浅蓝灰外壳；内容区更浅；白色筛选卡、KPI卡和图卡用极轻边线区分。标题/数值为深蓝，操作主蓝明显，辅助文字与网格退后。顶层导航使用线性图标，分节使用无凸框的底线导航，分析切换使用蓝底白字选中块。间距与左右基线一致比额外阴影更重要。

当前实现已发现：QTabBar无Fluent替换，analysis_mode_combo/chart_style_combo把明确模式隐藏到菜单，stats_style.initialize_theme仍使用旧#2369c9/10pt，而tokens是#0067C0/逻辑像素。必须修复样式源与实际控件连接，不能只新增tokens文件却不使用。

## 3. 分段控件的确切实现路线（修正早期泛指SegmentedWidget）

已检查当前库源码：默认SegmentedWidget绘制白色选中块和底部短线，并非原图的蓝底白字。不能只把ComboBox换成该类即宣称达标。

由C单独拥有新增frontend/stats_controls.py，提供共享FluentSegmentedControl。组合现成qfluentwidgets.TogglePushButton与Qt互斥QButtonGroup，保持Fluent按钮原生hover/pressed/checked/focus行为；组容器提供连续浅边/6圆角，按钮checked按tokens.ACCENT蓝底白字，未选透明/浅底。禁止使用PillPushButton的独立药丸外观，也不另造绘图按钮。

公开接口：FluentSegmentedControl(parent=None, compact=False)；addItem(key:str,text:str,icon=None)；setCurrentKey(key:str)；currentKey()->str；setItemEnabled(key:str,enabled:bool)；currentKeyChanged=Signal(str)。setCurrentKey语义与用户切换一致，调用者需要blockSignals时显式处理。首次addItem默认选第一项；同项重复设置不发信号；禁用项不可用户激活。B/C使用同一组件，不各复制实现。常规36高/14字，compact28高/12字；图卡标题不足宽时把按钮组整体移到下一行，不挤掉标题或缩字。

## 4. 全局配色和字体接入

stats_tokens.py作为唯一来源，stats_style.initialize_theme必须设置tokens.ACCENT和字体，旧局部QSS中的旧蓝/旧字体要逐处替换。标准正文14px，不把10pt误当14px；QtCharts也用QFont.setPixelSize。

页面#F4F8FC，外壳可用同色或略深浅蓝灰，白卡#FFFFFF，边框#E3EAF3；文字#18314F，辅助#65758B；操作蓝#0067C0，数据蓝#1677FF，第二公司#00A67A。同一公司颜色在名称、KPI、图例与曲线上一致。

禁止全局QWidget选择器强行白底或给每个QLabel涂背景；以语义对象/组件边界作用，避免破坏其他页。共享外壳、三个统计页及弹窗全覆盖；其他已存在页面使用相同共享按钮/字号/色彩，不改变无关业务。

## 5. 布局职责与密度

- 1600×1000基准：导航192，内容左右20，板块间16，卡内12–16；禁止整页横向滚动。
- 页标题与文件区约76高，Pivot约40，筛选常态两行；快捷日期使筛选高度下降，不为每个字段另造一行。
- 第一行公司/范围/粒度/分析按钮组；第二行实际时间/提醒/导出。同期额外周期控件合理占第二行或新增一行，不能隐藏导出。
- 公司单视图：紧凑公司名后六KPI一行，简短工具栏后2×2图；双公司摘要3×2，图卡/数值对应行对齐。移除4个图位大下拉，换成图卡头部指标菜单。
- 网络总体/公司比较：摘要与图分区，六KPI按3×2，公共图区3/2/1列；同期各公司列内单列图。原图仅六图不构成删掉第七八图的理由。
- 不给每层都套明显边框。层级=外壳→白表面→文字/图；不要白色父卡+白色子卡+图内灰框三重嵌套。
- 弹窗、长公司名、长数值、窄宽重排必须实看，不使用无限setMaximumHeight把内容裁掉。

## 6. 派发与验收关口

图形允许集公开接口：C提供ChartPanel.set_mode_options(modes: tuple[str,...])。公司现金流仅('trend-bar',)，其他公司指标仅('line','area')；trend-bar为时间柱状，bar为分类条形，不得混用。单项时可隐藏无意义的切换控件。有效当前模式保留，否则切到首个允许模式；set_mode不得激活允许集外模式，未设置限制时保持既有行为。空集/无效键显式拒绝，全屏副本保留允许集、当前模式及图例状态。B通过此API接入，不直接隐藏C的私有按钮。

图卡指标入口公开接口：C在ChartPanel提供set_metric_menu(menu: QMenu | None)，兼容RoundMenu。B构造并持有六指标菜单、当前勾选和切换回调，保留图位互换避免重复的语义；C负责标题旁Fluent轻量菜单按钮、辅助名称及窄宽布局。传None隐藏入口，替换时解绑旧菜单但不删除调用者持有的菜单。B不得通过_layout、chart_views等私有成员注入控件。指标菜单与常显的图形类型分段按钮分别存在，接入后移除四个全局图位ComboBox。

B负责外壳/主题初始化/Pivot/筛选/KPI/公司网络页面布局和弹窗；C负责共享分段组件与图卡内部/图例/坐标/全屏。所有权明确，C先提交共享组件便于B接入；B不要私自复制。
