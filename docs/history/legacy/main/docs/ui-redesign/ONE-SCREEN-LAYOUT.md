# 常用分辨率一屏布局验收

2026-09-29。验收环境为 Windows、系统缩放 100%、Qt 逻辑 DPI 96。以完整主窗口 `1920×1080` 和 `1440×960` 为目标，而不是仅以图卡容器尺寸代替窗口尺寸。真实单人 `望春市6.save` 和双人 `quicksave.76561198362520556-76561198845688243.save` 均须实际加载。

## 硬要求

- 网络总体：单人六项摘要、八张图；双人五项摘要、七张图。两目标尺寸下全部图卡边界都在可视区域内，横向与纵向滚动范围均为 0。不能删图、折叠、分页、裁切或藏滚动条。总览摘要取消单独的“● 总体”标题行。
- 公司默认：单人和当前双人存档的全部六项 KPI 与四张核心图（双人各四张）在两目标尺寸内可见，横向与纵向滚动范围均为 0。双人继续左右分栏且对应图同量程。多于两家公司单独评估，不能由双人结果推断无限数量均能一屏。
- 网络公司对比保留九图，尝试三列三行；同期保留每家公司八图，尝试公司栏内两列四行。若某尺寸不能在坐标、图例、单位和操作入口可读的条件下一屏容纳，须以实际可视高度、卡片下界与滚动范围报告，不能改业务语义掩盖。
- 日期与同期控件、标题、筛选、摘要和图卡按实际视口尺寸紧凑排布。保留合理字号与点击区域。城市页布局暂不修改。

## 实现与真实存档复验

主标题和三个页签在宽窗口共用一行。网络总体摘要取消“● 总体”标题，单人六项与双人五项 KPI 均排成一行；八图排成四列两行，双人七图的第二行由三张等宽卡片填满。所有带双选项的网络图都将窄按钮放在图题同行。分类图例色点靠左、两字标签完整显示，整组居中且在窄卡中保持一行。窄卡图题缩小并保持单行；“平均运行车辆数”在窄卡显示为“运行车辆数”，完整名称保留在提示中。柱形图使用轻微渐变。

公司默认与同期图卡、公司对比的共用图卡按视口高度调整。网络公司对比九图为三列三行；双人同期每家公司八图为两列四行。多公司总体不提供总覆盖率：“任意”是每家公司各自的总组，无法直接表示两家公司合并后的覆盖人群。

城市页内容布局本次未调整。双人网络同期保留轴、单位和图例可读所需的最低高度，因此较小窗口仍需滚动。图表标题去掉重复图标，数据卡片的切换按钮改为弱强调样式；窄同期图卡将两项图例放入标题行，并取消重复的周期说明。180 像素高图卡的有效绘图区由 49.5 增至 91.5 像素。

六分类同期图卡的两个汉字图例在 400 像素宽时排成一行，“本期 / 环比”说明移到标题栏；同高图卡的有效绘图区由 41.5 增至 71.5 像素。图卡和数据卡片的紧凑切换按钮均由同一个控件生成弱强调选中态，适用于总体、多公司和同期模式。

筛选区新增“确定”按钮：点击后收起筛选控件，在余下宽度显示公司、时间范围、粒度、模式及同期设置，并保留“展开筛选”入口。收起用约 167 毫秒加速动画，展开用约 250 毫秒减速动画，参考 [Windows Fluent 动效时长和缓动曲线](https://learn.microsoft.com/en-us/windows/apps/design/motion/timing-and-easing)。折叠不改变筛选值或查询令牌。双人网络同期在 1920×1080 收起后纵向滚动最大值由 138 降至 0；1440×960 由 446 降至 315，1600×1000 由 410 降至 279。

截图覆盖单人六种、双人九种页面模式在四种尺寸下的完整窗口，共 60 张；另有 23 张需滚动页面的筛选收起状态和一张 1440×960 分类比例图。见 [截图目录](one-screen-evidence/README.md) 和 [逐项测量数据](one-screen-evidence/measurements.jsonl)。测量记录了筛选与视口、每张 KPI 与图卡的边界、有效绘图区、DPI 与滚动范围，并完成 1440→1600→1920→2560→1920→1600→1440 连续调窗复测。原始存档哈希在截图前后相同。

另以真实双人存档执行 1440×960 至 2560×1440、每次宽度变化 16 像素的 141 步往返调窗检查。逐步断言公司默认页的公司卡、KPI 和图卡均在视口内，图卡行不重叠，横向和纵向滚动均为 0。修复前 1600×1029 曾出现图卡重叠与底部裁切；修复后该尺寸两排图卡间距为 6 像素，见 [复验截图](evidence/company-resize/company-default-1600x1029.png)。

统计页的公司、网络、城市滚动区现共用 Fluent 覆盖式滚动条，并支持触控滚动器、触控板像素增量与方向键滚动。所有卡片内紧凑切换控件统一使用浅色选中态；筛选区的模式切换仍使用强调色。见 [滚动条与按钮样式实测截图](evidence/scroll-style/README.md)。
