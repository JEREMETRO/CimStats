## 图形与颜色

- 公司现金流为时间柱，其余趋势统一轻面积折线；没有折线/面积切换。网络时间柱/分类饼等用户明确要求的切换仍保留。
- 折线约2逻辑像素，边缘抗锯齿；线下同色微渐变，上沿约8%–12%透明度，向真实零基线或绘图区边界渐隐至0%–2%。阴影仅沿数据线低强度呈现，约6%–10%透明度、1–2px偏移、柔和边缘，不做粗重光晕。参数是调试起点，最终看真实截图，不能靠堆阴影显得“高级”。
- 填充不能跨缺失断点。负值从零基线向负方向填充，不改变数据映射；不新增平滑插值造成过冲。同期填充更轻，保持当前/对比的实线虚线与文字识别。多公司重叠不得把趋势遮成色块。
- 时间柱细且端部柔和，柱内轻微同色明暗渐变，幅度克制，不加立体高光。稀疏柱约8–14px起点，密集组按宽度缩小，保持公司与周期并列。零值无假高度，负值与零线准确。
- 所有图表共用语义tokens：同一公司名称色点/图标/图例/当前线柱的基准色完全一致，绘制器不得另改色相或饱和度。渐变和阴影仅由同一基准色派生透明度；对比色规则统一。KPI数字和公司名用统一深色正文。操作主蓝与数据身份颜色分工明确。
- 分类横条、环形饼与趋势图使用同一字体/表面/分类色表，不加繁重渐变或阴影。类别与公司两种身份编码不能混淆。
- 少量淡水平网格，无厚L形轴或装饰性刻度；金额负值时保留必要零线。单位横排轻标，日期可读。常态不显示每个采样点圆点；hover只突出当前位置，tooltip准确展示真实值与日期。

## 实施边界

C负责共享tokens、图形绘制、阴影渐变、图例/tooltip/全屏/导出；B负责页面与图卡接入、移除多余切换及响应布局，不交叉修改公共绘图文件。允许复用现有FluentChartView，不另起演示项目。称为“PySide6 Fluent风格实现”，不声称使用官方Pro图表或原生WinUI。
