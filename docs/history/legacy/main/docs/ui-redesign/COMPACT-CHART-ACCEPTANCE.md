# 公司图卡紧凑布局验收

2026-09-29。公开接口 `ChartPanel.set_compact_layout(enabled: bool)` 供公司页在宽卡使用。默认关闭；网络和其他既有调用的绘图区高度不变。全屏副本继续采用宽松布局。现金流的时间柱状模式键为 `trend-bar`。

紧凑模式将宽卡的图形分段放到标题行，图例按可用宽度换行；减少图卡内距，QtCharts 画布边距归零，时间图 `QChartView` 最小高度设为 195 逻辑像素。实际测得 700 像素宽图卡最小高 **247**，现金流绘图区 **145.5** 像素、折线 **146.5** 像素，日期、刻度和负值零线未裁切。350 像素窄卡将分段移回标题下方，不强行压缩标题。

页面截图使用 B 的真实 `MainWindow` 演示脚本和合成历史；运行时只给图卡注入本工作树代码，并临时以 248 像素图卡高度试排，未改动 B 文件。当前 B 页面还需再释放约 37 像素的纵向空间，随后由页面会话以实际最终布局、真实存档和不同 DPI 重新验收。不要把图卡固定压到 230 像素：该高度下 QtCharts 的绘图区低于约 145 像素的可读起点。
