## 自查

- 单人总体六项摘要在 1600 宽窗同排，920 宽窗换为三列两行，覆盖率仍显示；多人总体五项摘要同排，下方七张图，没有覆盖率空卡和空图。两种窄窗的横向滚动最大值均为 0。
- 公司比较及同期使用每家公司“任意”总组画覆盖率曲线；同期两段日期均落在保存的历史内，图中可见实线本期和虚线同期。
- 大金额、客流、百分比、倍数与单位同排；车辆卡片保留“运行车辆”标题。
- 公司色用于公司身份标记、所属 KPI 图标及同公司系列；双公司同期图例色点与蓝、绿两家曲线分别一致。普通功能图标使用蓝色。分类横条、堆积柱与饼图类别色稳定，时间柱及横条采用同色微渐变，数值轴和下部图卡可见。分类横条与饼图证据均为动画完成后的清晰状态。
- 图形按钮按能力显示“趋势／分布／比例”，切换不改变底层数据口径。城市页沿用原有默认色板。
