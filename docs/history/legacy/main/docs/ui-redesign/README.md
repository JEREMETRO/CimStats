## 用户后续修订优先于原图

- 删除建筑图标、说明、状态和更新时间组成的公司摘要头部，只保留识别公司所需的简洁名称和色标。
- 三种分析模式互斥：默认模式、多公司对比、同期对比。不能把默认双栏误当成同图多公司对比，也不新增混合比较模式。
- 默认统计上一完整周，可选上一完整日；自定义通过日历设置，日常不展示两个必须手填的日期输入框。
- 同期对比默认上一段等长时间，可选上周同期、上月同期或日历自定义。
- 公司数据、网络数据、城市数据三个子选项卡。默认四张图、六指标均可切换。
- 所有子会话均在同一个项目根目录内的指定工作树工作，不创建平级项目或额外工作树；不使用子代理代替子会话。
- 只允许回收站移除，不永久删除用户文件或旧工作区。

原图是视觉参考，不是业务数据或指标单位的来源。当前真实指标、单位和缺失值规则继续以现有统计模型为准。
