# 线路查询增量改造与验收记录

保留 PySide6 + QFluentWidgets 框架，使用统计页共享字体、颜色、圆角、Fluent 表格/滚动/分段控件，以及不改变卡片位置的共享悬停阴影。以下说明仅用于交付记录，不加入程序界面。

## 保留字段

线路名称、公司名称保留在详情标题；稳定线路身份键、原有排序、选中联动、公司/制式筛选及原有导出不变。线路列表底层数据保留14列，按用户最新要求从查询界面及显示列菜单移除折算km，展开列表浮在详情上方显示其余13列；折算里程仍保留在模型和原有导出。默认核心列为线路、发班、最大需求、今日客流、每周收入。

默认九张卡片全部显示以下 17 项：线路车库；开线日期、最近改线日期；地图里程、站点数；单程时间、核定速度；当日发班数、平均间隔；理论最大车辆需求数、平均车辆需求数；今日客流、平均客流；今日平均单班人次、今日平均车公里人次；每周收入、每周支出。保留显示字段菜单，取消卡片指标切换箭头。今日经营指标仍指模拟当日，平均客流沿用原统计范围。首末班保留在所选日组时刻表摘要；站点客流入口按用户后续要求移除。

## 班次与运营规则

班次逐条保留，不按 HH:mm 去重。四类车型仅以文字颜色区分；原始车型缺失显示—，不伪装任意车、不增加第五种颜色图例。次日班次使用灰底，矩阵只画完整 HH:mm。悬停只显示当天合并总表发班序号、完整时刻、车型，使用复用单实例的QFluent ToolTip浅底、圆角和阴影；换格、离开、滚动、隐藏、尺寸变化和重新加载时关闭，遵循减少动画设置，并按悬停点所在屏幕夹取位置。普通Qt提示统一浅色样式。

矩阵按 05:00 运营日分界连续排序；摘要按圆周相邻至少 180 分钟的停运空档确定完整运营段，连续段跨过 05:00 不人为拆分，没有 180 分钟空档时显示 00:00–24:00。全天运营矩阵从00:00开始，不按05:00截断。早高峰 07:30–09:30、晚高峰 17:00–19:30 各自显示平均间隔，并有两种淡色衬底；夜间 00:00–05:30，其余平峰；按原始 tick 保留秒精度，不跨停运或不连续时段计算。缺失运行日和无效时刻保留原记录及异常状态，不猜日期或写成有效零值。字段可用性元数据区分缺失里程/站点与正确的0，卡片和列表统一显示—；依赖未知里程或不完整班次的派生指标同样显示—，原数值键保留供旧消费者兼容。
