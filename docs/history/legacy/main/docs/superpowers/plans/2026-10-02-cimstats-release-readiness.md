# CimStats 0.1.0 验收与 GitHub 发布准备计划

> 执行方式：沿用已授权的用户可见子会话，使用 superpowers:executing-plans 逐项实施；不另建平级项目，不自动发布。本文只作计划，未执行历史改写、文件清理、打包或上传。

**目标：** 将完整验收过的 CimStats 0.1.0 整理为可公开、可构建、有准确文档和许可说明的仓库及发行候选。

**架构：** 保留现有 PySide6 / Fluent Widgets 程序和业务结构，按明确文件清单接入候选补丁。源码仓库、用户发行附件、本地研发证据分开管理，不在发布前进行无关大规模目录重构。

**技术栈：** Python、PySide6、Fluent Widgets、现有图表引擎、PyInstaller、GitHub Actions。
