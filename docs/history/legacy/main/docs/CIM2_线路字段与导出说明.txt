多人公司归属
多人存档的 root.m_players 保存玩家和 CompanyData。每条线路通过 LineData.m_depot.m_owner 关联到 CompanyData；公司序号、玩家 ID 和公司名称已附加到线路、配车、时刻表、发班记录及站点客流表，并另行导出公司信息和公司车型数据。

可直接用于后续游戏内/注入式读取的字段映射：
- 配车：LineData.m_vehicles；每个元素的 LineData+Vehicle.m_vehicle 指向 Vehicle；Vehicle.m_line 指向线路。
- 发班：LineData.m_timeTables；TimeTable.m_startTime、m_endTime、m_interval、m_activeDays、m_rows；TimeTableRow.m_departure。
