# CIM2 SaveStats v0.6.2

正式本地发布；日常入口为项目根 `dist/CIM2_SaveStats.exe`。发布源码为提交 `96e8361cf645a80b3571a07317e6e1e913d14401`，附注标签为 `v0.6.2`。本仓库未配置远程仓库。

原有现代化公司概览、线路查询及深色侧栏保留；统计中心作为第三页，提供公司、服务规模、客流和城市四个看板。指标口径及换乘系数不可计算的原因见源码包中的 `docs/CIM2_统计中心指标口径.md`。

本目录的 `package/` 与正式 `dist/` 的三个文件逐字节一致；`source.zip` 是构建提交的源码快照。`validation.json` 原样保留隔离工作树真实验证任务的绝对路径，不改写为主目录路径。`embedded_runtime.json` 记录已审计程序集、重新生成的探针、其他运行依赖的来源，以及从冻结 EXE 抽取的 15 个内嵌文件哈希。`evidence/` 保存数值、程序集结构和界面核对材料。

v0.6.0 因统计正确性与界面状态缺陷未发布；v0.6.1 因构建期间所取程序集与审计基准不同，保留为中间候选。程序集变化本身不等于存档不兼容，本版已验证两份 Modifier 工程存档可读。
