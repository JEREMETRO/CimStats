六种制式的标识及速度、停站参数已与本机 GameShared.bundle 的 VehicleTypeObject 核对。
真实存档覆盖公交、无轨电车、水上巴士、有轨电车；现有样本没有地铁、单轨线路。
地铁与单轨通过资源参数核对和标识映射回归，尚无这两种线路的真实存档端到端测试。

n3 主存档及其副本在当前修复前源码和现有发布 EXE 的抽样复现中可解析，未能复现每个用户报告的失败。
n4 主存档稳定复现旧读取器漏掉 0x26000 偏移、5 字节零填充的错误；n5 主存档有同类边界。
新的容器读取器统一支持页对齐边界和旧的零填充候选，并校验 magic 与完整 DEFLATE EOF。

原默认 pytest 扫描误收集 archive/recycle_bin 下 test_duration_path_formula.py、test_method_calls.py，
两者因旧探针导入路径失效报错；pytest.ini 现在只收集当前 src 测试，不更改历史研究脚本。
