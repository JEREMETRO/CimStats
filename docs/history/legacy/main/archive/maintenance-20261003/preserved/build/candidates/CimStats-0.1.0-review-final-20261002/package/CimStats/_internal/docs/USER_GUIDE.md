# CimStats 用户指南

对应准备中的0.1.0，尚无完整公开发行包。当前可能仍显示旧品牌或版本。

## 打开与时间

用“打开存档”或支持拖放的主窗口读取自己的.save，等待解析完成。切换文件建立新任务，旧结果不应回填；保留原始存档备份。

日期来自游戏模拟时间。默认上一完整周，可选上一完整日或自定义；完整周不意味着历史一定完整，没有基准不能生成变化。

## 页面

**最新信息：** 城市与时间、运营概况、线路亮点、趋势/结构、提醒。“今日”按模拟时间。

**线路查询：** 筛选、详情、展开只读时刻表。计划班次不同于已完成客流，不写回存档。

**公司数据：** 现金流、公司价值、月票、满意度、声誉、受欢迎程度。默认分别展示公司；多公司模式横比；同期模式比较每家公司本期与基准，默认上一等长区间。

**网络数据：** 总体仅含已选公司，不自动扩大到全市；横比至少两公司。摘要车库/站点、平均/最大车辆、客流/出行量切换不等于改变全部图形。总体覆盖率暂不显示，可靠峰值缺失时最大车辆不可用。

**城市数据：** 全市，不受公司选择影响。五项摘要与六张图；交通方式有效构成才画饼；出行时间默认平均线，可选实际群体，缺有效权重时平均不可计算。

## 操作

- 图例显隐不改变分母；摘要可折叠恢复。
- 悬停查看实际日期、系列、值、单位和必要缺测信息。
- 放大应保留筛选与图例；当前大图排版仍在验收。
- 导出前确认范围、粒度和保存位置，再分享结果。

## 常见问题

有值却无变化：可能没有有效基准，真实持平与缺失基准不同。

只有一个点：一日范围配日粒度只有一个桶，可切小时查看日内变化，不插值造点。

“—”代表缺失或不可计算，0代表真实零。

加载失败：记录版本、游戏/模组、错误和复现步骤，移除个人路径与身份，不公开整个存档、DLL或jobs目录。

0.1.0正在接入仅图标启动页与关于弹窗，组件通过不等于所有入口已更新。

开发任务通常在根jobs；独立程序沿用%LOCALAPPDATA%/CIM2_SaveStats/jobs。品牌改名不清空旧数据。详见[指标口径](DATA_DEFINITIONS.md)。
