## Game and proprietary/runtime boundaries

Cities in Motion 2 is developed by Colossal Order and published by Paradox Interactive. 游戏及 Unity 相关名称、版权和商标归各自权利人。本项目与这些公司没有声明官方关联或背书。

当前旧 EXE 含 Assembly-CSharp、UnityEngine、SteamworksManaged、游戏自带 Mono/System/Boo/Zlib 等 16 个 DLL；历史 source.zip 含探针、UnityEngine 和可选 Bridge 共 3 个 DLL。游戏原 DLL 和基于它修改的探针均不属于项目全权拥有的作品。未获证据的游戏/Unity/探针 DLL 不进入公开源码/二进制的建议允许清单。随游戏取得的开源 Mono/Boo/Zlib DLL 也须核对具体版本来源与原声明，不能仅凭名称获准携带。

Steam 游戏页指向 [Paradox User Agreement](https://legal.paradoxplaza.com/eula)，其对 UGC 的许可不转让游戏和第三方材料的权利；[Steam agreement](https://store.steampowered.com/subscriber_agreement/)也不是任意复制游戏文件的许可。查到的 [Unity runtime terms](https://unity.com/legal/editor-terms-of-service/software)面向满足其条件的项目创作者，不能当作从他人游戏取出 UnityEngine.dll 的独立再分发授权。具体旧 Unity 版本适用历史条款或单独授权未取得，因此仍排除这些 DLL。

可选 Bridge 是项目 C# 反射辅助代码；其当前 4096 字节 DLL 只引用 mscorlib 4.0.0.0，未嵌入游戏程序集，源代码与游戏探针应分别判断。可公开项目自有源代码；其编译产物须绑定对应源码及 GPL 告知，且不能随附游戏/Unity DLL 或把与游戏组合运行授权推定为已获许可。公开源码建议只带 Bridge 源码与构建说明，不带预编译 DLL。

## Fonts and brand assets

Microsoft YaHei UI / Segoe UI / Segoe UI Variable 当前仅由 Windows 本机字体数据库使用；frontend/static 和旧 EXE 未发现这些字体文件。旧 EXE 的 38 个实际字体来自 Matplotlib，按原始许可判断，不能与 Windows 系统字体混同。禁止把 Windows Fonts 中的 TTF/OTF/WOFF 当项目依赖复制，除非另有相应授权。[Microsoft font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq)

批准的 C+三柱符号 SVG 是项目重新绘制的路径/渐变，不内嵌字体或外部图像；设计批准与版权/商标授权是两个判断。参考图片权利链及品牌资产独立授权尚需记录。CimStats 字标 SVG/outline JSON 的轮廓来自 Segoe UI Semibold；不能把字形轮廓宣告为项目原创字体或由根 GPL 自动覆盖。完整单词的 PNG 图形输出与字形/字体文件分发分别判断；可编辑轮廓源暂不进入公开允许清单，待确认图形输出范围或换为明确可再分发的字标设计。不得重新打包系统字体。

本轮只补入法律文档和许可文本，未修正 spec/build/publish 的内容选择。当前构建配置仍嵌入游戏 DLL；docs 中两个 UI 证据缓存目录还有 4 个 Unity/探针 DLL 会被不受 .gitignore 限制的文件系统收集重新带入 EXE。当前发布脚本仍漏收根 LICENSE/NOTICES/许可树并纳入游戏 DLL；因此按当前脚本生成的包尚不能标记“可公开发行”。源码 git archive 只取 HEAD 已跟踪内容，应与文件系统打包风险分开核对。
