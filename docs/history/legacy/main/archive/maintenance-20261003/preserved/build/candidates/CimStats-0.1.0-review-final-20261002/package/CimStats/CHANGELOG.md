# 版本记录

## CimStats 0.1.0 — 开发中，尚未发布

新品牌从0.1.0开始编号，作者JEREMETRO。以下是本轮范围，不表示所有功能已通过最终验收；旧1.0.0及以下保留为CIM2 SaveStats本地历史记录。

- 公司、网络、城市三个统计子选项卡，统一Fluent界面与强调字体。
- 最新信息首页、线路与时刻表布局更新；首页默认浅蓝，保留正蓝调用模式。
- 恢复有效变化指标，区分缺失基准、真实零与持平。
- 新品牌图标、仅图标启动页及紧凑关于弹窗正在接入。
- 完善用户、开发、指标、贡献、安全及发布文档；第三方分发边界单独审计。

发布前仍需关闭大图布局、网络对比自适应、启动与关于主窗口验证、版本接入及整体验收等事项。当前记录不作为公开安装包发布声明。

## 1.0.0 — 四看板 Fluent 界面正式版（2026-09-27）

- 浅色侧边汉堡菜单与四看板统计页；小窗口自动重排，保留其他页面业务。
- 分群体、分制式、分区各自切换总量／条形图／折线图／饼图；恢复同公司同窗口统计换乘系数。
- 统一零基线和整数数值轴，真实小数值不取整；缺失数据不补零。
- 统计提醒支持已读持久化；统计PNG和XLSX共用查询结果。
- 不新增未经批准的页面解释文案。完整要求和验收证据索引见 docs/stats-ui/。
- 使用 QFluentWidgets 浅色控件、蓝白看板与稳定公司配色；修正长名称、窄图时间标签、数据切换叠印及多公司城市展示。
- 保留公司概览与线路查询功能及原有 XLSX 导出；修正侧栏点击路由和过期解析回调，补齐旧页回归。
- 数据、异步和视觉独立审核后更新版本；全量167项通过，统一 Microsoft YaHei UI 并修复旧页面留白、控件与详情滚动。经用户批准发布至 dist，原0.6.2保留归档。

## 0.6.2 — 构建依赖固定候选

- 便携构建核对已审计的 `Assembly-CSharp.dll` SHA-256；安装目录被修改时，可使用明确指定且哈希相符的备份。探针在临时目录重新生成，打包后逐文件校验 EXE 内嵌内容。
- 打包后的解析进程始终使用自身内嵌的探针和 Managed 运行库，避免图形界面传入的安装路径与探针来自不同程序集；此项不限制读取模组存档。
- 0.6.0 因统计正确性问题未发布；0.6.1 在安装目录变动期间取用不同程序集，未作为固定依赖的最终候选。安装程序集变化本身不代表存档解析不兼容。

## 0.6.1 — 统计中心修正候选

- 修正公司价值历史值的单位、部分当前小时的聚合权重、比例提醒阈值及无效筛选的数据残留。
- 趋势在缺失小时断线并显示模拟日期；公司颜色按稳定标识固定，同名公司附标识；增加分组多曲线和三方式占比差额说明。
- 对比明细与原始导出保留较长比较区间的额外周期，悬浮同时显示两侧日期和值；卡片与提醒补齐相对变化及双区间信息。
- 统计查询支持取消，关闭窗口会等待后台线程结束。0.6.0 候选未发布。

## 0.6.0 — 统计中心候选

- 新增公司、服务、客流、城市四个看板，按游戏模拟小时、自然日、周一至周日、自然月查询，并提供同存档时间对比、明细、原始小时追溯和 CSV 导出。
- 完整加载历史指标，保留原始分组、分子分母及玩家稳定标识；多人同名公司数据隔离，历史环形数组时间重建。
- 依据游戏历史写入逻辑汇总周期量、期末存量、平均值和加权比例；当前小时、部分周期、缺失数据均有完整度标记。
- 加入可调变化提示及换乘系数的数据不足说明。指标口径见 `docs/CIM2_统计中心指标口径.md`。

## 0.5.1 — 2026-09-25

- dist 只保留当前正式版的 EXE、README.md、VERSION.json。
- 新版运行任务统一写入项目根 jobs；独立便携版使用本地用户数据目录。
- 构建只写入 build/staging，发布前强制检查文件清单、源码提交、SHA256 及真实存档验证凭据。
- 发布归档不可覆盖；验证旧 dist 已归档后才替换当前入口，失败恢复旧目录。
- 将旧 dist 和旧版本包内运行数据迁出，逐文件校验并保存迁移清单；中间包标注非正式发布。

## 0.5.0 — 2026-09-25

- 统一存档容器读取，支持压缩流页边界前只有少量或没有零填充的有效存档。
- 补齐无轨电车 `trolley` 标识，集中管理六种运输制式及别名。
- 桌面列表、排行、极值卡片、详情、网页及线路报表共用线路名规则。
  空名显示线路号加“路”；单字母追加末尾；数字开头的自定义名称原样显示。
- 后端明确输出 UTF-8，修复发布版状态栏中文路径乱码。
- 线路列表增加今日平均单班人次、今日平均车公里人次。
- 移除不能写回存档的班表编辑与方案组入口，保留只读班表和历史研究。
- 整理历史源码、限制运行模块打包范围，并建立测试和版本发布记录。
