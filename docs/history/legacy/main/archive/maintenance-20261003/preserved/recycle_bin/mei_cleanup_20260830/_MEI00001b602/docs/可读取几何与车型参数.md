# 可读取的几何与车型参数

## 车型资产

从安装目录 `CIM2_Data/Data/Bundles` 的车型资产中可读取：

- `GeneratedVehicleInfo.m_length/m_width/m_height`：车型长、宽、高，固定点除以 1024 为米。
- `VehicleObject.m_maxSpeed`：车型最大速度内部值。
- `VehicleObject.m_acceleration`、`m_braking`、`m_turning`：加速度、制动、转向内部值。
- `m_capacity`、`m_sizeClass`：容量和尺寸等级。
- `m_maintenanceRequirement`、`m_fuelConsumption`、`m_electricityConsumption`、`m_quality`：维护、燃料、电力和质量参数。
- `m_trailers`：挂接车辆关系，可用于计算编组总长度。

当前目录文件：`exports/CIM2_车型尺寸速度目录.csv`，包含 149 个公共交通车型。

## 道路资产与存档道路

道路类型资产 `Roads.bundle` 和存档中的 `RoadData.m_type` 可读取：

- A/B 方向车道数；
- 左、右人行道宽度；
- 站台宽度；
- 公交专用道、停车道、路肩、人行街、高速路标志；
- 最大车道数、道路类别；
- 存档实例的 `RoadData.m_length`、道路半径、起终点路口和车道数组。

当前道路类型目录：`exports/CIM2_道路类型宽度目录.csv`，共 15 种类型。宽度字段同样是固定点除以 1024 为米。例如普通道路两侧人行道各 4 m，快速路两侧各 2 m，轨道道路两侧各 2 m，电车道路两侧各 0.5 m，avenue 的站台宽度为 8 m。

程序集没有单独的“标准车道宽度”字段；若需要完整断面宽度，应按车道数、人行道/站台宽度和道路 prefab 网格进一步计算。线路里程仍使用 `RoadData.m_length` 和 `LineData.CalculateSegmentLength`，不能用覆盖半径或道路断面宽度替代。
