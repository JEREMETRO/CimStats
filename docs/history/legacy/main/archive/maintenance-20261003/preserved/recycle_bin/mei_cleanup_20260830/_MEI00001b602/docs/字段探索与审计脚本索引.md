# 字段探索与审计脚本索引

本目录记录历史阶段用于反编译、字段探查、运行时探针和拟合分析的脚本。为保持正式统计程序目录整洁，这些脚本已按类别移入 `archive/recycle_bin/field_exploration_20260830`，没有删除，仍可追溯使用。

## 保留的正式脚本

- `extract_runtime_data.py`：解码存档并通过 v1.6.3 程序集模拟对象图导出 CSV。
- `build_line_workbook.py`：生成线路信息、公司概览及逐线路发班工作簿。
- `build_company_workbook.py`：生成公司信息、人员、票价、周收支工作簿。
- `build_passenger_workbook.py`：兼容旧版客流工作簿导出。
- `build_cim2_workbook.py`：原始 CSV 汇总工作簿。
- `extract_geometry_catalog.py`：提取车型速度/尺寸和道路宽度目录。
- `build_field_inventory.py`：生成可统计字段清单。
- `audit_*.py`、`validate_*.py`、`verify_workbooks.py`：当前仍使用的审计和验证工具。

## 已归档脚本类别

- `tmp_*.py`：临时字段、字节流和签名探查。
- `probe_*.py`：Unity/程序集运行时探针。
- `disasm_*.py`、`dump_*.py`：IL 反编译和方法输出。
- `inspect_*.py`、`find_*.py`、`lookup_*.py`：字段、方法和引用检索。
- `analyze_*.py`、`fit_*.py`、`compare_*.py`：历史拟合、对照和分析。
- `count_*.py`、`diagnose_*.py` 及其他早期专项脚本：阶段性诊断。

归档脚本依赖的文本、CSV 和中间结果也随同历史产物保存在回收站目录；最终导出文件和当前审计结果留在 `exports`。
