# CIM2 SaveStats 桌面前端

## 启动

开发环境中，在项目根目录运行：

```powershell
py CIM2_SaveStats.py
```

便携版发布目录中双击 `CIM2_SaveStats.exe` 即可启动。程序不联网，也不修改原始存档。

## 导入存档

- 将单个 `.save` 文件拖入窗口；或
- 点击工具栏“打开存档”，使用 Windows 文件选择器选择文件。

程序会自动判断单人/多人存档，并显示公司、线路、车辆、时刻表和发班记录数量。首版只处理当前选中的一个存档，不扫描文件夹，也不修改文件关联。

首次运行会自动探测 Steam 下的 `CIM2_Data/Managed/Assembly-CSharp.dll`。若未找到，使用“设置安装目录”选择 `CIM2_Data` 或 `Managed` 目录。程序集必须与 Cities in Motion 2 v1.6.3 相匹配；程序不会随包分发游戏程序集。

## 查询和图表

“公司概览”显示资金、资产、声誉、车队和制式收支，并提供资产、车队和收支图表。“线路查询”支持线路号、公司、运输制式和名称组合筛选；选择线路后可以查看地图/折算里程、单程时间、核定速度、客流、车辆需求、各日发班和站点客流信息。

线路地图里程遵循当前统计口径统一乘 2，折算里程保留游戏程序集值；时刻表按周一至周四、周五、周六、周日分组，时间显示为 `HH:MM`。

## 导出

工具栏提供两个导出入口：

- 线路 XLSX：线路信息、公司概览和每条线路工作表，客流已合并；
- 公司 XLSX：公司信息、人员、票价和周收支。

导出前可选择目标文件名和位置。临时解析目录位于 `jobs/`，任务完成后保留本次结果供导出和复查。

## 打包

在 Windows 开发环境执行：

```powershell
pyinstaller --noconfirm --clean CIM2_SaveStats.spec
```

生成的 `dist/CIM2_SaveStats/` 即为便携目录。请将 `src/`、`data/Assembly-CSharp.probe.dll`、`data/UnityEngine.dll` 和 `data/` 中的运行时依赖与 exe 放在同一发布目录结构中；不要将游戏的 `Assembly-CSharp.dll` 复制进发布包。
