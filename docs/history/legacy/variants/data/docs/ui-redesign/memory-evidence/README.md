# 解析内存曲线基线（优化前）

2026-09-30。五份真实save各串行两次，100ms采样，完成后先前存档与根probe哈希均不变；runtime/导出/中间文件临时隔离。使用同一桌面进程中新的窗口对象，未清OS文件缓存、未重启系统，属于首次/重复运行，不宣称硬冷启动。没有并行解析负载；系统其他应用继续运行。保存桌面RSS、解析子进程树RSS、系统已用/可用、子进程CPU秒及原阶段权重；列定义见profiles.json。

## 预测函数

S为存档大小MiB，当前流程预计解析实际完成耗时：

T(S) = 5.825852931 + 0.651925911 × S （秒）。

解析子进程树峰值预测：

M(S) = 157.363176122 + 11.626413655 × S （MiB）。

训练为首轮quicksave、望春市6、Friday、Friday2；完全留出Saturday首轮，另用全部五档第二轮验证。有效范围 **22.9822–32.8643 MiB**，这台机器/当前未优化管线，不能外推其他大小或设备。

读取阶段将RSS历史最大值H/M(S)与训练数据的归一化单调内存曲线反插值，得到读取阶段已耗时间比例q。全程估计：读取对象阶段p=max(p_previous,min(99,floor(100×[0.75×t/T(S)+0.25×q×r]))))；r是训练中读取耗时/总耗时的中位数，41个内存/时间knots和r见model-validation.json。后续阶段不再使用骤降的子进程RSS，改用t/T(S)，仍保留单调及99%上限。真实完成事件才能100%；失败/取消不作完成。系统总内存因其他程序、文件缓存、GC而有大噪声，仅诊断，未纳入百分比。

验证6次运行的耗时预测相对误差 −7.45% 至 +3.12%。预计进度的平均绝对误差1.77–5.12个百分点，最大11.45个百分点。这里的对照是`当前已耗时间/最终实际耗时`，**不是已反序列化对象比例或业务工作量真实完成度**。后段内存回落、重复运行和系统背景噪声均在原始曲线可见；单调高水位仅解决显示倒退，不能消除估计误差。
