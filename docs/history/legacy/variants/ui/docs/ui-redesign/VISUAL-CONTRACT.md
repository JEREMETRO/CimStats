## 2. 页面几何与层次

1. 窗口保留原生最小化、最大化、关闭。工作区背景 `PAGE_BG` 连续延伸到导航旁，不使用重蓝渐变或模仿 Mica 的原生窗体依赖。导航展开宽 `NAV_WIDTH_EXPANDED=192`，窄态 `NAV_WIDTH_COMPACT=48`，行高 `NAV_ITEM_HEIGHT=44`；保留程序已有的可用入口。选中项为 `ACCENT_SOFT` 底、`ACCENT` 字/图标、左侧短竖线。
2. 内容区水平页边距 `PAGE_MARGIN=20`，窄窗可为 `NARROW_PAGE_MARGIN=12`。标题区左侧约48图标底座、29号标题和简短现有功能说明；右侧是文件图标、长文件名省略、存档时间、主“打开存档”按钮和“更多”。文件名悬停及辅助名称保留完整文本。顶部控件按同一基线排列，宽度不足时合理换行，不能遮住打开操作。
3. 标题下是**公司数据／网络数据／城市数据**三个图标加中文子选项卡，激活项蓝字与底部细线。网络数据承接既有服务规模与客流，城市数据承接原城市看板，不删除已有指标。
4. 子选项卡下为一张白色筛选表面。常态第一行是公司多选、统计范围、时间粒度、互斥分析模式；第二行是实际区间说明、提醒阈值、关键变化提醒及导出。同期模式增加对比周期选择，可在行内/新行重排，但导出必须仍可见。公司标签可逐个移除；日常不展开两个日期输入。自定义范围以独立日历面板选择并有应用/取消和字段内错误。
5. **窗口标题、页面标题、子选项卡、筛选卡固定**；只让其下的数据内容在一条纵向滚动区域内滚动。双公司不能各有一条内部纵向滚动条，也不能引入全页横向滚动。空数据、加载和错误占用数据区，不推动筛选栏消失。
6. 模式由明确状态 `default`／`companies`／`period` 控制，三者互斥。默认模式按公司分组且每图仅本公司；多公司对比为公司KPI分组及下方公共四图；同期对比按公司分组且每图比较该公司两个时间段。选择公司数不改变模式。零家公司显示明确空状态；多公司对比只有一家时保留KPI并提示至少两家，已有单条数据可以留在公共图中。
7. 公司分组头仅有**色点与名称**，名称截断时 tooltip 和辅助名称提供完整名称，重名使用公司 ID 消歧。不要建筑插画、宣传文案、状态/评级胶囊或更新时间。分组的视觉边界可由留白/轻边框形成，不复刻大摘要卡。
8. KPI次序为现金流、公司价值、月票使用率、满意度、声誉、受欢迎程度。单公司宽屏一行六卡；双栏每家公司3×2。小图标在左，标签/数值/单位有清楚层级。单位从 `Result.metric.unit` 获取，例如现金流是模型的“货币”，不能照抄示例“万元”。
9. KPI与图卡之间有简洁工具栏，提供满意度维度、图表样式/指标及全屏相关入口，不加重复大标题。默认四图位：现金流、公司价值、受欢迎程度、月票使用率；六指标可切换（另外两项满意度、声誉）。切换至已在其他图位的指标时交换位置。多公司栏位同位置及满意度维度同步。

## 3. 颜色、字体、间距、轮廓

`stats_tokens.py` 的颜色全部是 `str` 类型的 `#RRGGBB`，可以直接用于 QSS，QtCharts 中用 `QColor(token)`。`COMPANY_COLORS` 是有序 `tuple[str, ...]`。尺寸、字号和阈值为 `int`，均按 Qt 逻辑像素使用；**字号调用 `QFont.setPixelSize` 或 QSS `px`**，不要混用 `QFont.pointSize` 或截图物理像素。图表线宽、不透明度为 `float`，不透明度取值0–1，用 `QColor.setAlphaF`。无 Qt 导入，导入模块不会建立 `QApplication` 或更改主题。

| 用途 | 常量和值 | 应用规则 |
| --- | --- | --- |
| 基底/卡片 | `PAGE_BG #F4F8FC`，`CARD_BG #FFFFFF`，`SURFACE_SUBTLE #F8FBFE` | 大背景连贯；白卡贴近原图；subtle 只用于轻工具区和空状态，不做一层又一层白卡。 |
| 边与字 | `BORDER #E3EAF3`，`BORDER_STRONG #C8D6E7`；`TEXT_PRIMARY #18314F`，`TEXT_SECONDARY #65758B`，`TEXT_DISABLED #98A8B9` | 1逻辑像素浅边框，文字仍有对比；禁用态同时改变交互能力，不能只变灰。 |
| 交互蓝 | `ACCENT #0067C0`，hover `#005BAA`，pressed `#004A8C`，soft `#E8F2FC`，focus `#0067C0` | 控件主蓝和导航选中统一；图表蓝独立用 `CHART_BLUE #1677FF`。错误边/字用 `ERROR_COLOR #B42318`。 |
| 图形 | `GRID_COLOR #E8EFF6`，`AXIS_COLOR #BCCBDD`；曲线宽2，网格宽1，面积不透明度0.10，对比期不透明度0.45 | 水平轻网格为主，轴线细，绘图区透明/白色与图卡连成一片；周期再用实/虚线区分。 |
| 公司 | `COMPANY_COLORS` 首项蓝 `#1677FF`、次项青绿 `#00A67A`，其余为紫/橙/玫红/青/橄榄/灰紫 | 对每份存档的**全量公司 ID 稳定排序**后分配，不因当前选中子集重排；色点、KPI强调、图线、图例、tooltip保持同色。超过颜色数时可循环，但图例继续用姓名/ID区分；颜色不表示经营好坏。 |
| 字体 | `FONT_FAMILY=Microsoft YaHei UI`，回退为 `Microsoft YaHei`、`Segoe UI`、`sans-serif` | 正文14，辅助12，图标题16，KPI数值21，页标题29；常规粗细400–600，标题600–700。QtCharts字体也设同一家族，中文必须实测可见。 |
| 间距 | `SPACE_XS/SM/MD/LG/XL = 4/8/12/16/20`；页边20，板块16，卡内16，关联控件8 | 卡片左边、标题、图位及文字基线尽量成列；局部紧凑先减内距再减字号。 |
| 圆角/高 | 大卡12，KPI/图卡8，控件6；标准控件高36；焦点线宽2、常用图标18 | 小控件无需逐个阴影；大表面/弹窗可用低透明柔影。触点不可因压缩而过小。 |

`stats_style.initialize_theme` 后续需以 `ACCENT` 设置 Fluent Widgets 的全局主题色，统计页 QSS 与图表分别消费同一模块。若样式库控件自带状态绘制，优先用其公共主题/样式接口；不要通过全局 `QWidget` 选择器破坏其他现有业务页。

## 4. 所有交互态的验收规则

| 对象 | 默认 | hover / pressed | 键盘焦点 | disabled / 加载 / 错误 |
| --- | --- | --- | --- | --- |
| 主/次按钮、图标按钮 | 主按钮蓝底白字；次按钮白底浅边；图标按钮留36高命中区 | hover用较深蓝或轻蓝底；pressed再压深一级，不移动布局 | 清晰的 `FOCUS_RING` 细轮廓，Tab可达，图标按钮有辅助名称 | 灰化且不能触发；加载不重复提交，保留原文字或可解释进度 |
| 下拉、分段模式、公司多选 | 白底浅边；选中状态蓝字/浅蓝底；可移除公司标签 | hover加深边线，pressed反馈，展开菜单沿控件对齐 | 焦点环包住整个可操作区域；弹出菜单支持方向键/Enter/Esc | 禁用时文字与箭头一致降级；零选中显示占位，不暗中选择所有公司 |
| 日期面板及范围字段 | 常态只见快捷范围和实际起止文本；自定义时弹双日期日历及可选时分 | 日期格 hover/选中明确；应用才提交，取消无查询 | Tab顺序为起点、终点、时分、应用/取消；日历方向键可用 | 无效起止禁用应用，字段内红边/中文错误；历史不足显示提示但不改用户选择 |
| 开关/阈值/导出菜单 | 视觉尺寸与36高控件协调；导出在筛选右侧可见 | 全部有相同深浅反馈，菜单项有hover高亮 | 菜单与对话框焦点可见，Esc关闭且返回触发控件 | 查询中导出依据有效快照控制；错误/空数据不显示旧快照值 |
| 图例、tooltip、全屏图 | 图例含文字与色/线型；tooltip含公司、指标、周期、真实日期、数值及模型单位 | hover仅强调对应值和点，图例切换仅控制可见性 | 图例和全屏按钮Tab可达，tooltip文本可读 | 缺失值为断点/“—”，不补0；无数据占位保留图卡结构 |

弹窗、菜单、提示与全屏图遵守同一字体、边框、颜色；不能主体用 Fluent 而外围落回原生 Qt 灰色外观。选择、加载、空值、错误状态不能仅靠颜色传达。页面不添加虚构的运营状态、评级或额外业务字段。

## 5. 图表实现约定（C可直接消费）

- 图卡白底、轻边、8圆角；左上小线性图标与标题，右上紧凑图例、全屏操作。绘图区与卡片同一白色，不显示 QChart 默认背景/厚边。四图的绘图区左右边、图例行高度和 X 轴日期基线对齐。
- 默认现金流是时间柱状（现有 `ChartPanel` 的 `trend-bar`，不是分类横柱 `bar`），其余折线；非现金流可切换为面积折线。线宽 `CHART_LINE_WIDTH=2` 逻辑像素，点密集时不常驻逐点圆点，hover才强调；面积用 `CHART_AREA_OPACITY=0.10` 单色填充。QtCharts `QLineSeries`、`QAreaSeries`、`QBarSeries`、`QPen`、`QBrush` 可实现，无需 WebView。
- 轴和网格用 `GRID_COLOR`/`AXIS_COLOR`；少量水平网格，图宽不足时跳过部分日期标签，tooltip保留真实完整日期，不旋转密集标签。现金流含负值保留零基线；百分比、评分与货币各自按模型单位绘制，不共用不相关量程。相同指标的所有可见公司合并有效当前/比较值后由 B 调用 `nice_axis` 与 `set_axis_spec`；C按其 scale、上下限和刻度呈现。
- **多公司对比**同图每公司一系列，按稳定公司 ID 色表；现金流同时间桶的柱并排而非遮挡。**同期对比**只在本公司图叠加本期/对比期，本期为该公司实色实线，对比为同色低明度虚线；柱图同桶并排。图例必须同时含周期文字与线型，不能只用浅深色区别。
- 缺失 `Bucket.value is None` 为断点；不画假零、不跨断点插值。比较区间不等长时仍保留所有比较数据，按相对周期位置显示；tooltip用各自真实日期。hover联动只广播相对本期起点的秒偏移，程序响应联动时不再回发，避免信号回环。
- 图例显隐、全屏、hover、样式切换只影响视图，不更改 `Result`、查询结果、XLSX单位/数值。演示截图可以用明确标记的固定 fixture，业务界面与导出仍使用真实快照。

## 6. 响应式与实现接口

以**内容宽度（扣除导航和页边）**判定：`>=1120` 时双公司等宽，每栏四图2×2；`720–1119` 时双栏保持，但每栏图表单列以保证轴可读；`<720` 时公司组上下堆叠。单公司 `>=720` 四图2×2，否则单列。三家以上默认/同期按同样公司栏网格两列多行。多公司公共图 `>=720` 为2×2，窄于720单列。导航在小窗收窄，筛选控件重新换行。主要核验1600×1000；复核1920×1200、1366×768、920×680及125%/150% DPI。小窗可纵向滚，但不得横向丢失操作。响应式改变只调整布局，不改变分析模式、指标或数据。

此规范与现有 PySide6 实现相容：页面已有 `NavigationInterface`、Fluent 控件、`QScrollArea` 和异步任务；图表已有 `ChartPanel.set_result`、`set_mode`、`set_axis_spec`、`clear` 以及 QtCharts 网格/笔/图例。B继续持有模式、时间筛选、公司 ID→颜色映射及同指标轴范围，B的卡外工具栏负责指标选择；C负责图卡内部标题/图例/全屏。C消费 `stats_tokens.py` 并实现合约中公开的 `set_company_palette(dict[str,str])`、`set_hover_offset(float|None)`、`hover_offset_changed`，新增 `area` 模式，同时保留旧模式调用。若图卡全屏需新增公开入口，C先告知B准确签名，不让B读取 `chart_views` 等内部成员。双方不得从私有图表属性推断样式或给统计模型增添截图里的业务字段。`stats_tokens.py` 可独立导入；它不依赖尚未合入的 D 模块。

阶段验收时按三张实际运行截图核对结构，再核对长名、弹窗、空值、负值、DPI和三模式语义。每张截图记录逻辑窗口尺寸、DPI、模式、数据来源、提交号，且说明相对原图按用户修订删改之处。
