# CIM2 存档可统计字段清单

## 二、历史序列可统计字段

`CIM2_城市历史指标_完整_*.csv` 每条记录包含：公司名称、指标、分组、历史序号、模拟时间、值、分母、值/分母、百分比指标、增量指标、当前槽位。

当前可用指标包括：

- 城市与交通规模：`population`、`linecount`、`stopcount`、`depotcount`、`vehicles-running`、`trip-number`、`trip-time`。
- 交通方式与客流：`public-transport`、`private-motoring`、`walking`、`transport-by-type`、`transport-by-group`、`trip-types`。
- 经济与公司：`cashflow`、`company-value`、`economy`、`infra-value`、`vehicles-value`、`business-value`、`net-cash`。
- 服务质量：`coverage`、`popularity`、`satisfaction-speed`、`satisfaction-cost`、`satisfaction-quality`。
- 票价与逃票：`single-line`、`one-zone`、`two-zones`、`three-zones`、`four-zones`、`monthly-ticket`、`generic-ticket`、`fare-dodging`。
- 城市环境与人口：`traffic-density`、`energy-prices`、`unemployment`、`reputation`。

这些序列可以计算日/周趋势、环比变化、峰值、均值、分组占比、客流方式转移和公司价值/现金流变化。百分比指标优先使用 `值/分母`，增量指标优先使用相邻历史槽位差；不要把两类指标当作同一种数值相加。

## 三、可派生的综合指标

以下指标不直接存储，但可以由当前字段稳定计算：

1. 线路：平均单班人次、平均车公里人次、客流/站点、客流/公里、收入/公里、支出/公里、收入成本率、当前配车/最大需求、车辆周转率、各日期班次占比。
2. 站点：候车人数/今日客流、站点累计客流占线路累计客流、站点客流集中度（Top-N 或 HHI）、各分区客流占比。
3. 时刻表：各日期的首末班跨度、理论班次、班次间隔离散度、峰时班次、时刻表之间的重叠和缺口。
4. 公司：制式收入占比、制式成本占比、资产回报、车队利用率、线路平均长度、线路平均客流、车辆需求缺口、公司间效率对比。
5. 历史：客流与覆盖率相关性、票价与客流变化、现金流与公司价值变化、拥堵度与公共交通占比、各社会群体出行结构。

## 四、解释和限制

- `地图里程`不是 `RoadPathSegment.m_length` 的简单总和；必须读取每个非终端段引用的 `RoadData.m_length`。否则 161 路会被错误放大到 24.0809 km。
- `折算里程`、单程时间和最大配车需求使用 v1.6.3 程序集逻辑重算；多人存档中的缓存字段可能为旧值或零值。
- 线路“开线日期”是线路对象创建时间 `ObjectData.m_buildTime`。存档没有首次启用时间日志，不能从当前文件无损恢复首次启用时刻。
- 周收支的收入、支出和估算是当前状态的平滑周化值，不是存档时刻前 3 天的简单累计。正式报告周期按当前模拟周的周一至周日标示。
- `运行车辆数`是公司车型对象的当前快照；若要做时间序列，应使用带公司归属的 `vehicles-running` 历史记录。
