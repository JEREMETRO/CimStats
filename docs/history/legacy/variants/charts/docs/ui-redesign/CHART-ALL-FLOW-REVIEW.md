## 柱与饼图排版

现金流、出行量、客流及公司/对比期并列柱共用既有间距计算。柱宽上限详细图48px、小图20px；总值文字12–15px加粗，分段10–13px，无数值色底。细周期保留所有柱，密集数值由悬停/选择查看，粗周期短区间显示完整数值。单月两公司金额几乎相同时，柱外文字尝试小幅横移，防止两行文字无空间时重叠或落入柱体。负值仍在柱末端下方，零值与缺测口径不变。

饼图文字改为圆环两侧排序的外部标签，数值与百分比通过细引线对应真实扇区。详细图数值13px、百分比11px，两行；小图空间足够时单行，窄卡按真实文字宽度切两行并在10–12px内适配。两个 renderer 共用直径计算，为两侧文字预留空间，类别隐藏不改变原角度和占比分母。

中心不再写“总计”，只保留加粗数值及单位，数字在10–18px内按圆孔适配。极窄卡的完整长金额若在10px下仍放不进圆孔，在当前绘图区底部预留24px，用一行显示同一个总值和单位；圆心上移14px，扇区标签避开底部28px预算。每个字号候选同时计算底部预算、各侧单双行高度与行距，小图实际文字行高加2px间距，详细图4px间距。该处理没有新增数据或滚动。根分支 hide_center 继续生效。
