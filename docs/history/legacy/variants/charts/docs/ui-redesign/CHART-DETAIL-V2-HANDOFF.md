## 整改行为

- 详细时间图为每个原始观测保留真实时间位置和最小可读列宽，不抽样。图面所有真实值常驻，优先贴近实际点/柱/堆积段，低段高或拥挤时使用独立标注位置及引线。所有公司柱有总量；隐藏分类后明确可见/原总量。完整表保留，作用为核对和点击关联，已不替代详细时间图标值。
- 横向滚动覆盖完整时间画布，缩放改变列间距；选中屏外点、整柱合计或饼图切片会滚到对应图形。底部辅助表压至84–112px，详细汇总卡实际108px，24px数值层级与12px日期/单位。
- 未合并的多公司数据按公司并列、公司内分类堆积；多公司本期/比较身份分别保留。真实模型的总览聚合口径继续为已选公司总体；分公司模式才是公司比较。没有将总体合计宣称为公司对比。
- 详细模式使用全局趋势/分布/比例命名。真实客流模型仅允许趋势/比例，代表 QA 不再手造多余折线模式。
- 详细折线只对真实观测点执行 lineTo，无曲线插值；保留全部观测点。去除详细线的圆角连接和阴影，原有真实缺失断段保留。
- 标签排版按空间网格检查碰撞，并缓存矩形布局；每次绘制重新绑定当前数据身份与颜色。缩放、数据、隐藏、几何或文本变化使缓存失效。
