## 修正

定位到现金流绘制使用独立的 3 px 间距规则，且把完整柱值按柱宽压小，自动位置候选会落入圆角柱内。

两种图现共用 _grouped_bar_geometry。详细图公司间距按时间槽宽度的 7.5% 计算，上限 24 px，柱宽上限 48 px；紧凑图同样共用计算，间距最多 4 px、柱宽最多 20 px。长周期仍保留所有真实柱，不扩大画布。

现金流柱值采用总值文字样式，12–15 px 加粗且无底色，按实际数字宽度和相邻柱中心间距适配。正值在柱顶上方，负值在向下柱末端下方；零值保留真实零标记，缺失不生成数值。量程按实际视口高度为负值末端预留一行 32 px 的文字空间，正值量程保持原逻辑，窗口变化时重新适配。负值文字不再钳回柱内，密集图点击后的文字也遵守正上、负下方向，左右边缘保持可见。点击、悬停保留原 bucket 身份。密集标签的判断包含公司/对比期柱数。
