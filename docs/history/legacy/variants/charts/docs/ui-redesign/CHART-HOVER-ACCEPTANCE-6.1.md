## 修复与行为

- `FluentChartView.mouseMoveEvent` 不再把事件交给透明 QtCharts 系列，避免连续线段产生伪观测。所有屏幕命中来自实际绘制几何。
- 折线只接受观测点周围 8 逻辑像素圆形距离；多个近邻系列选实际距离最近的点。隐藏与缺失不命中，空白、插值线段及远点无 tooltip。
- 非零柱使用实际柱矩形，堆积段不扩大命中范围；隐藏段从堆积高度移除。真实零值以有限基线标记表示，缺失仍无标记。
- 同一堆积柱多个零值在宽图中使用分开的有限水平标记；密集图的可用宽度不足时，同一时间槽、同一公司/周期、同一累计基线的零值共用有限标记，提示列出全部实际可见零值，不创造柱高度、不汇总假值。标记按绘制层级优先于其下非零矩形，隐藏类别排除。
- 饼图按实际环形扇区命中，中心空洞、外部及隐藏扇区无提示。Tooltip 保留实际公司/系列、日期或查询期间、原值和模型单位；普通公司饼图补上查询期间。
- 空白、离开、更新结果时关闭旧提示。Qt 自身的 tooltip 关闭过渡是异步的，真实显示检查等待 500ms 后验证不可见。
- 跨图只接受相同相对时间槽（小于 0.5 秒的数值容差），不无限选最近日期。高亮位置来自 Fluent 实际标记，按图记录目标，重绘/resize 后保留并排公司/周期柱的偏移。
