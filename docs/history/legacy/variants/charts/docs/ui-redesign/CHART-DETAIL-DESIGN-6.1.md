# 图卡数值与全屏设计（2026-10-01）

用户已明确授权继续实施六项图表要求。本设计沿现有 ChartPanel/NetworkChartPanel/CityChartPanel 继承路径工作，不新增项目、不回填主目录，不重复解析存档，保留 f525605 的真实点 hover 修复。

## 展示与口径

移除三点指标菜单、页面菜单创建/接线和相关空位；保留原默认四图、满意度维度、网络图形切换、图例和全屏。放大克隆继续复用原 Result、快照、轴范围、颜色和隐藏偏好。

详细模式由父级 QDialog 自动识别，覆盖现有公司、网络及城市全屏克隆路径。顶部是按公司/本期或对比期组织的统计卡，每个系列分别使用 summarize_buckets；不跨系列相加存量、平均、比例。未确认口径和缺失显示—。筛选窗口以真实期间显示。主体占据余下可用空间，详细模式采用12px以上数值/轴文字和适量主次网格，饼图不再固定上限190px。

所有数据值都有始终展开的完整关联数值区。数值区保留真实零、缺失—、公司、系列、真实日期/期间、模型单位和显隐状态，支持滚动与选中对应真实点。数据多时使用 Qt 表模型而非创建成千上万标签。它是正常图卡的一部分，详细模式提供更大的数值区。

稀疏图通过有限候选位置和引线进行完整常驻标注。一次排版必须覆盖全部可见实际点、每个堆积分段和堆积合计；如果无法容纳全部标签，该图统一使用完整数值区，不留下任意抽样的图内标签。字号最低11px，详细图12px。数值区不会因标签布局失败减少记录。

堆积合计明确区分可见合计/原总量；隐藏不改变原总量。缺失分段导致相应未知合计显示—，不补零。密集零值仍保留f525605的有限共用基线提示，全部原值在数值区可查。

- 新增 `frontend/chart_details.py`：只读统计卡数据、完整数值行、表模型/数值区、常驻标签排版。与解析器和业务控制器解耦。
- `stats_charts.py`：移除指标菜单按钮；接入数值区和详细模式，增加主次刻度/详细字体，保留原hover与公共接口。
- `network_charts.py`：移除菜单位置依赖；接入结果/显隐更新，保持原descriptor与周期/endpoint语义。
- `fluent_chart_view.py`：基于实际绘制几何绘制数值/引线，空间不足时完整关联数值区提供全量；详细饼图扩大。
- `statistics_page.py`、`company_dashboard.py`：只移除三点指标菜单创建/接线，不改满意度维度或默认业务。
