字体、配色、Fluent控件、卡片阴影及页面动效复用另外两页的共享实现。没有引入新的导航页、示例警报或运营评级。

原11项指标、4个极值及分类数据取现有存档解析结果；线路集合按稳定公司ID和制式统一筛选。平均间隔保留原首页全部已启用且运行日已知日组的有效相邻间隔口径，不把它悄悄改成仅模拟当日。

新增公共交通分担率复用现有历史模型的全市公共交通原值，计算范围为模拟当日截至模拟时刻，保持全市范围。平均换乘系数复用现有换乘查询，在逐公司完整类别且分子、分母可配对的小时中汇总总客流/总出行量；全部公司即总体，选择公司即所选公司汇总，不平均公司系数。分母没有制式细分时明确标注全部制式。

今日趋势取现有小时历史，排除未来小时，缺小时断线，保留真实0。提醒独立查询上一完整模拟日与前一日，复用原提醒规则、三个阈值键及已读身份；缺测、不完整或不可比的数据不生成提醒，换乘系数不生成方向性提醒。
